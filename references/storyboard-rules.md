# 分镜创作规则总集

新分镜的实质规则只维护在本文件，按职责查对应章节；流程只读[分镜工作流](storyboard-workflow.md)，文本标记和命令读[文本母稿格式](storyboard-text-format.md)。新稿默认scene-text-v1，不另建字段密集JSON、动作效果计划、逐实体可见性表或逐镜审阅证据。旧专项页不再随包分发；本文件是实质创作规则的唯一入口。

目录：来源与节拍 → 表演与动作 → 声音与时长 → 摄影与空间 → 连续性 → 交付版式。示例和词库均有适用条件，不设题材、姿态、机位或表现配额；未适用项不填占位。

## 来源与节拍


范围简报只做一次，当前场用短节拍指明信息、关系或情绪的必要变化。写作按事件关系决定镜头，先确定观众必须读清的变化、整次发言的自然说法，以及动作、表情和声音的必要先后或同期关系；据此形成自然估时，再确定必要可见内容、取景与切点，校准镜长，最后切分和组合生成单元。每镜须具有来源支持的必要观看作用，并能说明当前人物、空间或事件相位与取景的关系，以及删除或合并本镜会损失的理解、表演或执行条件。有意义的观察、等待和保持可以成立，不要求每镜新增事实或事件。上述判断融入写作与独立审阅，不另写逐镜问答、`purpose`或全场时间计划。自然估时可随实际取景与信息可读性修正，整场时长由最终安排汇总得出。

原文事实、台词、发声类型、事件次数、明确先后与结果必须保留。首次书写时将来源明确要求的事件、动作、表情、状态变化及声画关系落实到对应镜头正文或声音行，用既有来源映射定位，合法省略保留具体依据。仅列来源记录、身份或完成姿态，不能代替本镜必要的过程与表现。要求按实际主体结构、感知条件和媒介适用，不能从人类表演规则推导其他主体必须具备的部位或反应。区分同时成立的状态、共同发生的动作和有必要先后的事件，文字罗列或分镜展示顺序不自动等于事件先后。多个主体共同传递同一信息、各自过程没有独立差异时，优先同镜呈现。必须分别读取的变化、揭示顺序或无法通过合理取景解决的限制，才构成拆镜依据。不得按人数逐人展示相同过程，或为满足参考镜数拆开共同事件。允许把已成立情境具体化为可演的动作与反应，不新增剧情、动机、关系、能力或结果，不从范围外借事件填时间。

人物站位写本单元真实起点，区分在场、可见与主焦点。单元内持续成立的衣装、基础位置、持物及布景关系集中在起点交代；各镜头承接这些条件，按当前取景写明实际变化，不重复展开与本镜理解无关的不变信息。持有、支撑、接触、视线、遮挡或动作因果影响本镜理解时，仍须在相应镜头落实必要状态，不能以起点已有说明为由省略。每个视频单元均须具备独立执行所需的当前条件，不依赖其他单元或后台笔记中的隐含状态。新单元从真实末态重新判断起点，不整段复制前单元站位；已结束的短暂手势不作为下一单元默认姿态。焦点的必要动作过程、可见情绪和相关参与者的反应/持续活动直接进入正文。只写当前取景确能看清的细节，不因未提及人物就判定其离场或画外。角色形象和道具引用沿已核实资产，不用临时别称掩盖已有资产。

作者直接写成可交付的画面、表演、摄影和声音句子，写作与工具的权限边界见[共同执行契约](execution-contract.md#分镜创作与工具边界)。构思理由、来源论证、方案比较及防错说明留在必要的工作笔记中，不重复写入镜头正文。正文与所属声音行共同承担实际执行信息，不另写一套逐镜说明或审核结论。精简不得改变原台词、事件、次数、声源及明确先后，也不得删除关键动作、反应、空间关系或观看所需的执行条件；不设置统一字数或压缩比例。


当前范围出现新图片参考需求时，只回查受新证据影响的候选/资产；prompt_only群像多镜出现不自动等于多次独立事件，不自动升级图片。确认漏项保留草稿并走绑定变更边界，不在现有session中虚称原位重绑定。

## 表演与动作

表演应将已成立的情境、关系、刺激和身体条件具体化为实际可拍摄的动作与变化，不要求原文逐字列出每个眼神和姿态。细化不得新增情节、动机、关系、重要次数、结果或未经确立的态度。汗泪、伤损、物件脱离以及改变后续行动条件的环境变化须有来源支持；原动作的常规局部物理反馈按本节“动作执行检查”处理。没有事件关联且不影响理解的背景无需强制刻画。

人物动作链在本镜确有观看负荷时，按当前已成立状态、可见进入相位或起势、关键动作或接触、直接结果以及仍有意义的收势或余波组织；只写本镜需要读清的相位，机械准备、中段和完成后空尾没有独立观看任务时直接省略或接入下一项。动作链必须由原文已成立的事件、关系、身体条件或当前场景物理必然性支持，不得借动作链新增动机、认知、决定、次数或结果。跨镜承接上一镜已经达到的动作相位，后镜不得无新依据重新起势或重演。

动作和表情必须使用可视化语言：写清可见部位的移动、接触、姿态及变化，必要时写明刺激位置、变化时机及落点。抽象心理、意图、情绪标签、作用解释和力学结论不能独立代替表演；判断应落实为当前取景能读出的视线、面部张力、头颈、肩臂角度、支撑、重心或运动变化。“意识到、感到尴尬、很有压迫感、情绪可辨、眼底翻涌”不能独立代替可见表现。脸红、汗水、泪光等外观变化不足以区分叙事要求观众辨认的情绪时，应补足符合已成立情境的表情、姿态或动作变化，不将外观变化固定对应为某种情绪。情绪名称可作简短辅助，但不能为具体化而补造心理和态度。内部规则中的“反馈、落点、反应、新增剧情结果”等判断或审核用语不得作为提示词说明输出，正文只保留实际画面和声音。

微表情属于面部可见的局部表演，只在当前景别、遮挡和清晰度能够承载时使用；可按需要写视线、眼睑、眉眼、嘴角、下颌、呼吸、头颈或肩背的具体变化，并绑定已有刺激、对象、发生时机和落点。微表情不等于固定的细微动作清单，不规定眼部先动、固定秒段或每镜完整情绪弧线，也不能凭单一肌肉、眨眼、瞳孔或眼角变化证明撒谎、真实情绪或人格。面部不可读时，改用当前画框内可见的姿态、支撑、接触、物件变化或同期声音承载必要信息，不补写被遮挡的表演。

视觉风格影响材质和表达方式，不自动决定动作速度、幅度、身体张力或情绪强度。各维度分别依据来源、身体条件及实际取景选择，不默认轻微、缓慢或克制；小幅或轻柔动作可以迅速发生，大幅动作也不必夸大情绪。冷静、克制或沉默可以通过明确注视、稳定支撑和果断的动作执行体现，不自动等于迟缓、松散或缺少回应。原文持续平静、沉默或静止时可保持；原有痛哭、狂笑、惊恐或强烈愤怒不得统一降为隐忍，也不为增强表现将不同人物统一改为大幅动作或高声说话。原文未逐字列出局部表演细节，不等于禁止将已成立情境具体化；细化仍须遵守事件、关系、认知和结果边界。细微表演和明显表演均按观看任务选择，不设置微动作数、全员反应、完整反应链或固定空白时长。

身体与声音方法只在主体实际结构支持时适用。动物、机械和非人形主体不补造眉眼、手足、呼吸或人类口型。FACS/AU仅可作为作者熟悉且核实的面部运动辅助，成稿用可见中文动作，不输出AU代码；不把单一肌群、眼角纹、瞳孔变化、左右不对称或眨眼频率作为真实情绪、真假话或人格的证明。

### 可见程度与强度

| 画面条件 | 表现粒度 |
|---|---|
| 中景/全景中确实可辨 | 只写看得清且有关的表情/视线，不因“全景”一律禁写，也不补读不出的肌肉细节 |
| 面部可读的近景、中近景、过肩正面一方 | 按需要用眉眼、嘴部张力、视线或头颈，不要求全套同时变化 |
| 面部为重点且原有重要转折 | 呈现起始、原触发和落点，必要时写中间过程；强度不超过来源 |
| 远景、纯背影、道具镜或面部遮挡 | 免除不可见面部细节，用可见的既有姿态、动作、接触或物件关系承载必要信息 |

表现强度由来源、人物当前身体条件和实际可辨程度决定；“轻微可辨、清晰但克制、明显、强烈”只作相对判断，不在成稿附评级。保持不要求眨眼、吞咽或呼吸声，强烈情绪也不能只靠程度词或五官变形表达。

必要信息不能因遮挡被遗漏，但有意遮蔽和延迟揭示仍须保留。先看实际露出部位、清晰度、动作幅度及可读过程；局部露出不等于细微表情可读。面部受遮挡时，应由实际可见的朝向、手势节奏、姿态、支撑或同期声音承载必要表达，不用被遮住的眉嘴承担主要表演。关键接触、压力变化或表情尚未被读清时，不得因运镜或切镜过早移开，仅写“仍在画内”不能代替实际可读性。取景承载不了必要信息时，在已有事件内调整机位、范围或切点，先解决关键看点，不默认将各主体的全部细节拆镜展示；不能擅自揭开遮挡、加声响，或写一句“情绪可辨”代替实现。

### 情绪进程与表里关系

焦点主体的表演围绕当前刺激、行动对象和话语作用组织。静态姿态不足以表达本镜必要态度或变化时，应具体写出可见变化发生的时机、方向和落点，不以眉眼、嘴角等静态部位清单代替表演。原文已有情绪变化时，从当前可见状态承接，在原刺激或语义产生作用的位置呈现变化；触发优先写原有动作或话语位置，不在动作正文重复抄写台词。依原情境选择直接变化后保持、延迟反应、短暂显露后收回，或原表情持续而局部变化；有意义的保持本身能够表达原态度时，无须另造变化。只写影响理解的环节，不要求每镜完整弧线，不规定眼部先于嘴部，不套固定秒段。延迟、收回和恢复均须有情境依据，不得为表演增加停顿或延后原文明示反应。

表里反差仅用于原文已确立的强撑、掩饰、言不由衷或矛盾状态。应保持观众与场内人物各自的知情范围、可感知条件和原有揭示时机；原文尚未揭示的内心不得通过新增微动作提前泄露，掩饰成功不得改成对手已经看破。需要让观众读出反差时，选择当前取景可辨的局部差异，不要求所有被隐藏的情绪都外露。原有内心想法os和画外音依“声音与时长”保留，不强制改成面部表演；来源中的`os/O.S./内心OS/内心想法`统一按内心想法os处理，`ov/VO/V.O./画外音`统一按画外音处理。

原文已成立的复合情绪可以局部并存、先后转变或被重新压住，不机械轮播多个表情，也不把矛盾情绪一律判为不相容。表面状态与局部变化分别写实际部位和时机；“表面温和、内里危险”本身不构成可执行表现。

下列示例仅说明来源状态如何转为可见表达，不规定同类情绪必须采用相同部位：

| 已成立的来源状态 | 可选表达 | 使用条件 |
|---|---|---|
| 强笑着听完，笑意随后消失 | 听时嘴角保持原有上扬，听完后嘴角回落 | 保留原有先后；仅有礼貌微笑时不得套用为隐藏怒意 |
| 惊色短暂显露，随即收住 | 上眼睑短暂抬起后恢复原有开合，朝向保持 | 面部确实可读，变化时机及被谁感知均符合原文 |
| 听后仍不露声色 | 维持原有表情与视线 | 不增加泄露内心的咬牙、躲闪或手部动作 |

### 部位表达与协同

以下词库按部位提供候选，须结合原状态、刺激及身体结构选用；不按情绪名称自动配动作，不把整行或全部部位填入每镜。

| 部位 | 候选表达 | 适用边界 |
|---|---|---|
| 视线 | 停在已知对象、随原动作转移、短暂移开后重新对上 | 明确实际对象与方向；不以躲闪证明撒谎，不用视线转移新增发现或认知 |
| 眉部 | 眉内侧轻抬、眉心聚拢、原有蹙眉渐松 | 描述可见变化，不由皱眉反推敌意、痛苦或人物动机 |
| 眼睑与眼周 | 上眼睑抬起、眼睑收紧、原有紧张逐渐松开 | 不将眼睑动作等同瞳孔变化，不默认增加眨眼、睫毛颤动或眼角纹 |
| 嘴部 | 原笑意维持、嘴角回落、双唇收紧、张口后收住 | 由原态度及实际发音决定；嘴角上扬或眼周变化不独立证明真笑、假笑 |
| 头颈与肩背 | 保持朝向、随已有动作转头、原有紧张放松、动作在原刺激处停住 | 与姿态、支撑及已有动作一致，不新增退缩、转身、握拳或接触行为 |
| 呼吸 | 中性起伏、已有屏息的解除、原有急促呼吸逐渐平复 | 屏息、喘息、哽咽须有来源支持；可见起伏不自动成为可闻音效 |

同一变化可集中在一个部位，其他部位维持；面部、头颈、肩背和呼吸可按情境先后变化，不机械同步，也不无依据地限定全身静止或只有嘴部活动。选择维持、出现、减弱、中止、收回或恢复时，应以已达状态为依据；不在每镜反复起势，不靠连续眨眼、吞咽或无意义小动作填充。说话时的嘴部动作须与发音相容，不能同时闭紧双唇并清晰大幅开口；声音选择及现场口型按“声音与时长”执行。

### 哭戏与强烈情绪

哭戏按来源已成立的阶段和强度呈现，不从悲伤自动推导眼泪，也不把含泪、落泪、抽泣和痛哭作为必须依次经过的升级流程。原文已在哭泣时直接承接当前状态；哭止后的湿痕、呼吸和声音只保留仍成立且有关的部分，不因切镜恢复干燥或重新落下同一滴泪。

| 来源状态 | 呈现重点 | 边界 |
|---|---|---|
| 含泪或忍泪 | 当前可见泪光、已有面部张力及其保持或变化 | 含泪不自动落泪，不补吞咽、屏息或肩膀颤动 |
| 无声落泪 | 已有泪水沿可见面部的运动、当前嘴部及姿态 | 不添加哭声、哽咽或新的崩溃动作 |
| 抽泣或痛哭 | 原有呼吸/发声中断、面部及身体变化的实际配合 | 保留原强度，按来源选用可见与可闻部分，不以五官扭曲替代过程 |
| 喜极而泣或哭笑并存 | 已成立的笑容、泪水与其变化关系 | 不凭眼角纹判定真实心情，不强迫哭与笑快速切换 |

已有汗泪按当前风格、表面、光源、姿态和重力表现；薄水膜、适量高光只适用于相应写实有机表面，不强套其他主体。明显悲喜、恐惧或愤怒同样须保留原动作及可见过程，不统一改为轻微表情，不为增强情绪新增泪水、伤痛、失控或破坏结果。

### 参与者与观看负荷

其他可见人物是否回应，取决于是否实际感知刺激及其回应是否影响本拍理解。保留原文明写的反应和持续活动，有依据的有意静止同样可以成立。同次刺激后的连续反应镜须分别承担来源成立且需要独立读取的必要事实、原有表演、态度差异、认知先后、关系变化、有效悬念或空间可读性；仅换人重复惊讶、凝视或沉默时，优先在合理同框、原动作或原发言同期中保留必要反应。是否单独取景按观看作用判断，不按人数分配镜头，也不设固定反应镜数上限。来源明确的认知顺序、重要揭示、悬念等待和喜剧节拍按实际作用保留，连续反应须合看累计信息与时长；不得为保留镜数新增态度、认知或微动作。各主体按实际位置、约束和感知条件响应，后镜承接已发生的反应进度，必要内容读清后接入后续已有内容。不要以“非焦点”为由一律静止，也不强制每个背景人物每镜活动；反应不抢主焦点、不代说或跟随他人台词做口型。真实画外、完全遮挡和模糊后景不写不可读的面部变化。

副反应映射只处理当前画框内确实受刺激影响、且其联动会影响本镜理解的参与者、衣物、道具或空气介质。焦点主体说话、发力、移动或改变状态时，按实际接触、受力、遮挡、气流、光线或声音关系写出可见联动；近景或特写无法容纳全局反应时，将必要信息转化为当前画框内的脸上光影、瞳孔反射、发丝或衣物掠动、焦外变化或有依据的画外声音。副反应不得新增人物动机、认知、决定或结果，不要求每个在场者每镜活动，也不能把换机位当作同一反应重新发生。

镜头需要的时间同时考虑必要信息识别、动作先后/接触因果及表演变化，不按人数、提示词长度或情绪类别套固定秒数。同一个动作、空间关系与声音可以同期传递信息，按“镜长与声音安排”处理共同时间，不机械拆成三镜或分别加时。大幅动作与面部细节需要同时读取时，应按主看点选择取景和信息量；必要时重排已有节拍或调整切点，保留关键表演，依据实际可辨程度和动作相容性决定是否同镜呈现。信息拥挤时先减少重复展示及无关说明，不为读清每项局部细节而拖长共同事件，也不为时长上限凑动作、停顿或运镜。

原文停在即将发生时不能提前给结果；接触或冲击本身不授权损坏、脱手或倒地。动作与表演的跨镜承接按“连续性”处理，人物之间不为避免重复而强行分配不同微动作。

### 动作执行检查

关键接触、持有转移、复杂姿态或易歧义动作写清谁执行、作用于谁或什么、哪一部位属于谁，按需交代路径、支撑、关键接触/中断和可见结果。多主体共同操作应明确实际参与者及各自操作对象，场内人数不等于动作参与人数。与行动组同框且容易被误纳入动作的其他主体，按其真实持续活动、持有或接触关系正向区分。同款道具仍按实际归属操作，不把共有造型当成共用一件实物。注视及指向明确实际目标和相对方位，换机位后仍是同一个对象。涉及来源已成立的屏幕或界面操作时，正文须让操作目标可辨、执行动作可见，并接到来源支持的结果或当前进度。目标可用已知位置、形状或已有关系定位，遵守画面文字限制，不为具体化操作补造按钮名称、界面元素或成功结果。非人主体用其实际结构，不新增器官或机制。只写消除歧义必需的项，不强迫每项动作填写统一清单。

当阻力、拥挤、负重、接触或惯性承担本镜信息时，应呈现决定观感的必要相位：在哪一接触或约束处改变，身体、衣物或接触对象怎样直接响应，进入什么状态；需要理解起因时保留相应起势。不因要求动作过程可读而逐项展开全部准备、机械中段和收尾，时间取舍按“动作节奏与转场”处理。不另填动作链表。不得只写“坐定、蜷缩、抵住、抓着”等完成状态而省略本镜必须看见的变化，也不得用“狠狠、巨大、用力”等程度词替代方向、接触、重心和速度变化。原文只需交代稳定状态时仍可保持，不倒补不存在的过程。

已成立动作在现有结构和材质上产生的常规、局部、可逆反馈可以具体化，例如衣料随屈膝绷紧、软包在膝部接触处轻微受压、重心下移后躯干收住。反馈须与受力方向、接触时机、材料和当前取景一致，强度不得把普通接触变成冲撞；材质未知时不得指定其独有形变。损坏、永久变形、伤痛后果、物件飞出及新增大范围环境变化不属于此许可。情绪本身不能驱动物理反馈。

原文未指定且不影响结果的执行部位可按真实结构确定并保持；决定结果的方向和接触位置不得猜。机械中段可压缩，关键因果与结果不能省。短暂动作的作用达成后进入合理收势、稳定或续行状态，持续接触及其结束条件按“状态更新与关联修订”判断，不统一规定保持秒数，也不因后文未写收势就延续已失去作用的动作阶段。

选择摄影之前，先判断当前动作所需的执行部位、支撑和操作对象是否可用。既有持物、操控或接触占用这些部位时，按真实状态及下述常规收置条件安排相容动作。关键交接、承重、制动、攻击或精细操作所需的部位与路径须实际成立，物件位于部位旁边不等于已被握持、支撑或操控。上述判断融入当前镜的书写，正文只表达本镜执行和理解所需的信息。

同一触发影响多人时，共用一个事件时间关系，各主体按实际条件响应。瞬时事件不因切换观察对象延长：保留关键触发、直接响应和必要结果，及时接入后续交互，不等前一人的全部反应完成后才让其他人开始感知或回应。跨镜承接已开始的动作相位，前镜完成后后镜不重新起势。仅写“同一瞬间”“只发生一次”不能替代可见进度。确需时间重叠须有清楚呈现依据，不把换角度默认当时间倒回。中断须发生在决定结果的阈值之前，不能一边写阻止一边已完成被阻止的结果。

例如，来源为“甲翻账本；乙指出日期不对后甲停手”，正文要让指错与停手的先后可读；下一镜承接已停在页上的手，不再翻一遍。没有面部变化依据就不补惊慌或吞咽。此例仅说明判断方法，不为实际项目新增动作或资产。


身体及环境反馈应沿原动作和实际机制成立，常规接触反馈与新增结果按前述边界区分；不得把“需要来源支持”解释为只许复述结束姿态。情绪本身不授权尘雾雨风、破坏、汗泪或超自然变化。

## 声音与时长

### 单元组织

- 剧情场次、剧情节拍、单镜和生成单元分别处理：一场可有多个单元，一个单元可包含多个连续节拍和多个镜头，一个节拍也可跨镜展开。自然语义/动作落点是候选切点；节拍结束、切镜、换机位或换说话人均不自动结束生成单元。单元数量不预设。
- 单元为4～30秒整数。切分与组合以已按剧情、表演、声音和观看负荷确定的自然镜长为基础。在来源连续、同场景、状态可承接、语义和动作关系完整且不超过30秒的合法候选中，优先选择26～30秒的组合；不存在此类合法候选时，按剧情自然落点切分。26～30秒只用于选择分镜单元边界，绝对不得参与单镜时长分配，也不得据此反推镜数、语速、动作速度、停顿或观察时长。
- 组合候选包括直接合并和在已有合法切点移动相邻单元边界，不能仅因现有两个单元合计超过30秒就认定没有可行组合。候选必须在不改动既定自然镜长、不破坏原事件顺序、完整语义和必要动作关系的条件下成立；若发现镜头本身存在实质问题，应回到镜头写作修正并重新估时，不以组合目标作为修正理由。26～30秒区间内按叙事完整性和承接质量选择，不额外追求接近30秒。
- 每个4～25秒单元在作者侧车的`unit_organization`保留具体边界原因；存在可行的26～30秒候选而未选用时，须说明其不满足的实际条件。仅“这一小段已经说完/做完”或“节奏需要”不足以解释放弃合法优先候选。正常26～30秒单元的时长分类由程序派生，不再要求作者重复证明已达到目标；不能由分类或原因文字推定语义合格。字段与例外记录只在[文本母稿格式](storyboard-text-format.md#文本分镜接口)维护。
- 每个单元的首镜与本单元人物站位共同建立独立可执行的起点；首镜直接写当前取景需要的姿态、位置、持物、视线或动作相位，不逐项填满无关条件。仅写“承接上一镜”“保持原文状态”或“承接某处站位与环境”不能代替可见状态。真实连续动作可以接续，但必须明确当前相位和必要关系，不依赖其他单元才能理解。最终组合后核对首镜是否重复已完成的准备或反应、末镜是否存在无依据保持，以及发声前等待、句内停顿、声音收束和跨单元原话分配是否相容。必要执行关系须在最终提示词可读，声音窗口合法不证明实际发声节奏成立。发现问题时调整合法边界或回改受影响镜头，不以补演前序事件建立独立起点。
- 组合已有内容，不补反应、停顿、无意义保持或放慢台词凑时长。镜头修订变短后，重新组织相邻已有内容及合法边界，原单元留下的余量不构成增加反应、延长动作或运镜的依据。可连续演绎的后续内容按真实声画关系接入，不把每个变短的节拍独立做成单元。安排边界时兼顾相邻单元和场尾的合法性，必要时重分已有节拍；自然尾段可以短于26秒，不为填满尾段打断必要表演、强接不兼容内容或超出用户范围。短单元原因按最终组合写入侧车，不另建独立理由表。
- 实际剧情场次改变时须结束当前生成单元；此项规定单元边界，不规定镜间必须采用硬切。原文明示且边界清楚的回忆/想象可在同单元明确进入/返回，总长仍不超过30秒。自然不足4秒时，先在用户已选范围内合并相邻且可连贯演绎的内容；仍不足才说明原因并请用户调整范围，不自行越界。旧入口保存的时长偏好只作诊断，不重新收窄4～30秒。
- 镜数由信息、动作、声音和节奏决定。26～30秒的8～13镜只作估量参考，不是上下限，不设默认11镜或按秒段分配镜数；不得为满足镜数拆碎表演、补镜或缩短生成单元。

### 镜长与声音安排

- 单镜1～6秒整数，时间轴连续且合计等于单元总时长；该范围是格式边界，不是镜长合理性的通过依据。动作执行速度、单镜观看时长及相邻事件之间的间隔须分别判断：快速动作可以在较长镜头的前部完成，后续时间须由仍在发展的结果、必要观察或原有表演承担；短镜头也可能因动作过载而不可读。镜头持续到本次观看任务完成：动作或信息已读清后，继续保留的时间必须有尚未完成的因果、信息、情绪变化或来源成立的观察、等待。场景空留、粒子消散、衣物飘动和姿态保持本身不能证明仍有观看负荷；它们承担明确叙事作用时才保留相应时间。不得仅凭4～6秒判为拖慢，也不得仅凭1～3秒判为紧凑。摄影方法按[运镜决策](#运镜决策与速度反差)选择。
- 镜长由信息读取、因果动作、声音和表演负荷共同决定。先确定来源事件的速度、必要相位、整次发言的自然说法及其实际先后或同期关系，据此估计共同执行时间；再按必要可见内容确定取景与切点，校准镜长，最后组合生成单元。摄影方案确实增加必要读取负荷时，回调估时或调整摄影，不能让事件等待摄影。不得先按单元目标或预设镜数分摊镜长，再把内容填入镜窗。仅同起点、连续且完全同期的部分可取所需时间的较大值；起点错开或部分重叠时，按真实依赖和最早开始至最晚结束的范围判断，必要先后才累加，不能用一个同期布尔值在全部取最大值和全部相加之间替代判断。转头、抬手、移动或站定不作为每次发言的固定准备环节，只有它们确为发声前提或延迟本身承担原有信息时才单独安排。不按动作名称、情绪类别或字数机械配秒。
- 动作、表情和声音的实际关系直接落实在正文衔接，正文与所属声音行构成执行依据。写明“先、后、等到、完成后”等必要先后时，须用镜头进入状态、动作所需过程和实际声音起点核对可用时间。若镜头从尚未做出表情或动作的状态起拍，发声前的极短间隙不能被当作可读的完整前置表演，也不能借侧车同期说明或未呈现的镜前过程补救。写明同期时，身体条件、语义和起止关系须支持同期，正文中的“动作完成后开口”与声音从动作开始时发出不能同时成立。正文改变先后、动作速度或完成条件后，须联动重估受影响的整次发言、声音窗口、镜长、切点和单元边界。内部解释或声音时码不能掩盖正文冲突。
- 每镜须读清必要进入相位、关键变化和结果或下一项有效变化；进入相位只保留理解动作所需的起点、方向和关系。切出状态可以包含仍在进行的动作，后镜承接其真实进度，不要求每镜独立完成起势、接触、结果和收势。关键变化完成后，剩余镜尾必须由尚未完成的因果、信息读取、反应、声音收束或来源成立的观察承担；没有这些负荷时，应在完成点切出或接入下一项相容内容。动作过程、起点和切点直接落实到正文，已经清楚时不按多个侧车字段重复抄写。普通镜头只保留简明自然时长依据，复杂同期、关键接触、等待或保持才补必要时间约束和继续观看依据；不强制为每镜分别填写动作秒数、观察秒数及小数完成点，不以未单列观察秒数判定没有观看负荷。
- 自然执行负荷先按实际语义、动作相位、身体条件和信息可读性估计，去掉无依据的等待、重复展示和串行准备后，在尚未取整的共同时间安排上做一次轻度节奏校准。可灵活部分以自然估时的约1/1.06为内部参考；该参考不覆盖原文明示速度、必要呼吸与哭腔、悬念延迟、喜剧停顿、关键接触及信息读取所需时间，也不要求不同题材采用相同绝对速度。声音、动作、运镜作为同一事件共同校准，不各自再乘系数；已校准的部分在修订时只重估受影响处，不叠加提速。内部估值、侧车说明及声音时窗不直接控制生成速度。镜长成立依赖及时开口、同期表演、短促接触或连续接续时，作者须把相应发生时机、进度和转入下一相位的条件写入最终正文或必要声音表现；不能只在侧车说明紧凑而在正文串行展开各阶段。不常规输出倍率、每秒字数、逐镜时间表或统一“快速”标签。
- 校准后按完整语义、动作相位和可读落点统筹整数镜长，再按“单元组织”组合。连续时间可在内部估算中细分，成稿镜头起止仍使用整数秒；不逐镜机械向上取整再把余量写成等待，也不把整数镜长统一除以系数后重排时码。单镜出现不足一秒的安排余量时，先检查相邻内容及切点能否合理重分，使原有有效动作、发言或必要观察自然承接。镜窗不足以容纳完整原话或关键相位时，恢复其所需时间，重分相邻镜头并按需移动单元边界；不能以剩余秒数反推某句语速，让同次发言的末段突然加速，也不为缩时吞字、抢拍或漏掉因果。不增加计时表或逐镜校准报告。
- 台词最低时长计算只用于发现镜窗绝对放不下的情况，达到下限不证明自然语气、必要动作和观看负荷已经合适。计算值不能自动决定镜长、拆句或单元边界；问题位置由写者按整次发言和声画关系重新安排，不能平均配秒、随机改秒或把余量写成等待来过检查。
- 短句优先完整放在一镜；画面已有必要切点时，不得为等整句说完而延长快速动作或无效保持。先考虑相容的声画并行；仍需跨镜时，按完整词组或语义分句分配原话，长句优先沿原标点和自然气口分配，不因切镜新增停顿。每段原话完整落在所属镜窗，拼接逐字还原原句，声源、发声类型及连续语势不变；不比例切字、拆词或孤立数字/语气词/标点，不用“继续说完”代替原话。语法和交付限制见[镜间表达与声音边界](storyboard-text-format.md#镜间表达与声音边界)。
- 发声安排使用文本中的声音标记，不另维护 audio_plan。按原话实际读法计可发音单位，数字、英文等先确定读法。常速约4.8～5.4、快节奏4.8～6、确需缓慢发声时约4.0～4.8可发音单位/秒，均为校准前的自然估时参考，不是适用于所有题材的语速硬上限；依据整次发言的话语作用、语言负荷、身体条件和明确发声要求选择，区间重叠不构成冲突，不由估算值反推唯一档位，也不按情绪名称自动分档。逗号、顿号约0.1～0.2秒，句末约0.1～0.25秒，只用于确需发生的停顿估算，不见标点就逐处添加；其他标点按实际语义处理。标点停顿、语义气口和片段间隙对应同一次实际停顿时只计一次，连续混合标点不逐个累加。发声估时承接本节已确定的连贯说法和必要气口，不另对语速、气口和句尾重复缩放。这些估值不能压过原语义，不作为延长镜头的依据，也不能为消除估时差异而添加气口、拖尾音或放慢动作。

以下例子用于区分执行速度与观看负荷，不作为题材或镜长配额；实际判断仍须结合来源与相邻镜头。

| 正文安排 | 判断依据 |
|---|---|
| 原文突袭，一拳在4秒镜头中持续缓慢接近，镜尾才命中 | 应修改：命中被无依据推迟；缩短准备与接近，重定切点或接入已有的有效后续 |
| 4秒镜头前部即完成突袭命中，随后呈现来源已有且仍在发展的受力轨迹及关键落点 | 可以成立：攻击速度未被拉慢，后续观看有必要内容；仍须核对结果未重复、时长是否足够且无空尾 |
| 2秒镜头同时要求完整接近、交锋、远距离飞行、落地及再次攻击 | 可能过载：须按实际必要相位和可读性重分，不能因镜短直接通过 |
| 6秒镜头承载来源已有的持续角力或必要整次发言 | 可以成立：负荷须支持镜长，摄影仍须符合运镜约束；不得另补等待凑足6秒 |


先保留原话、说话人、发声类型和明示情绪。声音表现写在引号外，原台词引号内逐字保真；原文明示的独立声响放音效，不能藏在视觉叙述里后又写“音效：无”。现场声、内心想法os、画外音、旁白及经复核的非人物播报均按真实来源判断。`os/O.S./内心OS/内心想法`是内心想法os的来源别名，`ov/VO/V.O./画外音`是画外音的来源别名；普通情绪、说话方式、表情和微动作括号逐字保留，不按声音类型别名改写。

情绪、音量、音高、发声质感、语速与停顿分别考虑。普通对白以清晰、连贯、利落地完成原有话语作用为创作基线，原文要求的迟疑、呼吸、哭腔、悬念和停顿按真实作用保留。“平淡、冷静、低沉、凝重、温柔、慵懒”不自动等于气声、软收音、慢速或长气口；内心声不自动变轻声、耳语或带回响。情绪或音色名称不足以表达具体说法时，依据既有语义与态度选择必要的字头、咬字、语义重音、句势和收音。连贯发声、随动作接入或句尾短收确为节奏成立条件时，在对应实际片段写明必要表现；不能用通用速度标签替代实际说法。强调优先通过适用的咬字、重音和句势完成，不默认拉长字音、句尾或句间空白。台词字词、标点及人物音色身份保持来源，不新增态度或情绪强度。估时档位不自动转写为声音括注，普通清晰陈述可省略括注，必要项按当前话语作用选择。

| 维度 | 可用表现与边界 |
|---|---|
| 音量 | 轻声、压低音量、自然音量、提高音量；轻声不自动悲伤，提高音量不自动愤怒 |
| 尾音 | 平稳/短促收住、轻微上扬、逐渐下沉；符合原态度，不凭问号设计嘲讽 |
| 发声质感 | 清晰自然、轻微气声、绷紧声线、已有沙哑；不制造伤病、哭腔或更换身份音色 |
| 咬字 | 连贯、字头清晰、收音轻、原文指定或由既有语义确定的重音；不改变句义或态度，不新增嗤笑、呻吟、吸气 |
| 停顿 | 原有停顿、完整语义气口或打断；切镜和表情标注不自动增加停顿 |
| 口型 | 只有实际现场声源且嘴部可见时按需写；听者、内心想法os/画外音所配画面不代说 |

画面与发言者可以分离：画面可观察原有听者反应、交互或相关对象，不按说话人轮流切面部；声画切换时机应服务信息接续和反应读取。同一次发言跨镜时，整句声音基调延续，各片段在正文中保持需要的表现；只有原文确有转折才改变。不能因切镜重新起调、换音色、拖句尾、重复吸气或额外停顿，依赖前后语义的列举与分句仍保持原关系。台词分段不得按字符比例；完整原话可以跨镜，发声片段须在所属镜窗内。声音标记与声画错位的表达边界见[文本母稿格式](storyboard-text-format.md#镜间表达与声音边界)。

声音标记的起止须与最终正文描述的执行过程一致，变更联动按本节声画关系规则执行。自然说法估时与已分配声音窗口承担不同作用，不能用窗口长度反过来证明语速自然；需要数值估时时，对整次发言保留一处自然估时，跨镜片段只记录必要分配关系，不逐片段重复自证或另建音频计划。普通同期表演不重复加时。文本估时与录音测量分别处理，仅用户提供并明确采用录音时使用实测。不要为了消除估计警告添加停顿。声音与可见表现存在反差时，按“情绪进程与表里关系”核对来源与揭示边界；发声表现写声音标记，可见变化写动作正文，二者不互相替代。方言沿原词和已确认需求，不套口型刻板模板。

同一声响跨镜只承接持续部分，不重新触发。嘴部状态由原动作和可见情境决定，不要求所有内心声画面都闭唇静止。场内真实发言者暂时在取景外不自动改成内心想法os或改换声源；只有来源明确标为画外音时才使用画外音。


音效应从实际动作及接触推导。原文明示声响必须保留；已有动作正常产生且有助于感受重量、材质、接触或空间的声音，可按已知条件具体化，不以原文没有逐字列出为由一律省略。按本镜实际保留的交互阶段考虑衣料与身体运动、脚步与承重、物件接触及环境底声，选取可闻且有叙事作用的部分，不规定每镜必须具备全部层次。当本镜保留的关键过程需要声音表现其重量或接触时，不应只填写结束时最显眼的一声；例如保留挤入软包座椅的必要相位时，可随实际呈现写衣料摩擦和落座轻闷声。不得为凑齐拟音层次重新展开已省略的动作准备、过程或收尾。

每项声音须对应实际声源、动作相位和必要的距离/方位/强弱，连续摩擦随动作延续，离散接触在接触时发生，不能将先后声音全部堆到镜尾。对白与关键声优先，细微拟音可低于对白，不为让声音显著而加重动作；普通接触不自动发出重击、破裂或老旧机构吱嘎声，衣物摩擦不自动等于撕裂。无须每个关节或表情都配声；真实不发声、远距不可闻或有依据的听觉省略可以不写，不能以固定“无”掩盖需要呈现的交互。音效直接写现有字段，不另建声音表。

禁止心跳、BGM、字幕和画面文字；原话依声源发声，标准稿保留的文字不因此变为屏幕文字。固定抬头及自定义风格原样，其他新写正文用中文及中文技术词，不额外交付英文版本。

## 画幅配置

新分镜先依据已冻结的`video_ratio`解析唯一画幅配置：`16:9`使用`landscape-v1`，`9:16`使用`portrait-v1`。画幅配置只约束同一来源事件如何被取景、组织和承接，不改变原文事实、事件次数、台词、声源、动作结果、声音时长或资产身份。来源事实、身体结构、物理关系、连续性、声音与时长规则始终优先；不能为满足画幅而删去主体、改写动作、添加事件或擅自越过范围。

比例选择只在项目入口保存设置；进入分镜上下文后才解析画幅配置。写者须在当前配置下逐镜作出真实构图决定，工具不得据比例自动填充镜头正文。独立主审按该单元冻结的配置阅读实际提示词；比例配置变更会使未提交草稿重新绑定上下文，已提交单元、回执和视频节点不被静默迁移。

### 横屏16:9配置

`landscape-v1`沿用本文件现有的摄影与空间、运镜、动作节奏、声音、连续性和交付规则。本节不替换、不改写现有横屏规则，也不为横屏增加宽景、横移、镜数、景别或动静比例配额。横向空间、左右关系和环境范围仅在当前观看任务需要且实际场面能够支撑时使用；具体取舍仍以现有规则为准。

### 竖屏9:16配置

`portrait-v1`只在项目比例为`9:16`的新分镜单元中适用。它是对现有摄影与空间规则的画幅约束，不是把所有镜头统一改成居中、近景或垂直运动。

- **主体与裁幅**：优先让主焦点沿纵向安全区域清楚呈现。全身镜头核对头顶、脚部和动作落点是否完整；中景、近景和特写核对面部、手部、关键道具及其接触关系是否留在可读裁幅内。重要主体或动作不能因为靠近边缘而被无依据裁掉；不需要看的身体部位不为填满竖幅而强行补入。
- **多人关系**：同屏人物、目标和操作对象按真实站位、前后景、上下层次或对角关系组织。不能因竖屏宽度较窄擅自删掉原文要求观众辨认的参与者，也不能把不在同一操作关系中的人物拼成同屏共同动作。若横向并列无法同时读清关系，应在已有事件内调整机位、纵深、裁幅或切点；只有同镜确实无法承载必要信息时才拆镜，并保留原有时间关系。
- **空间信息**：需要交代环境时，使用垂直纵深、前中后景、上下空间或有依据的逐步揭示承载信息。不能把原文关键的宽度、距离、阻挡或通路压成无法判断的窄条，也不能为了展示环境新增门框、栏杆、镜面、人物或其他实体。环境不是主看点时，不为竖幅凑满背景信息。
- **相机与动线**：可依据主体动线使用上移、下移、升降、垂直跟随、纵向推进或拉开；横向平移、横向跟拍和转向只有在关系、路径或信息揭示确实需要时采用。每次运动仍须写清开始时机、方向、途中保留的关系和终点，不能用“竖屏运镜”替代可执行路径，也不能让主体等待相机完成运动后才发生来源已确定的动作。
- **动作与道具**：手部操作、递接、持有、指向、接触和受力按实际部位及目标归属写入当前取景。狭窄裁幅不能把决定结果的手、道具、接触点或身体支撑留在画外；若本镜只需局部，必须明确局部与整体关系，不用孤立手部镜头掩盖参与者身份。
- **视线与连续性**：180度轴线、视线方向、运动方向、遮挡、出口和入口规则保持不变。换成竖屏后重新推导左右、上下、前后景和可见部位；画面坐标变化不等于场面位置变化，裁幅外、虚化或画外也不等于离场。跨镜继续同一动作时承接实际相位，不因换成竖屏重新起势或重复结果。
- **取景取舍**：竖屏可以使用远景、全景、同框、过肩、动作局部或近景，景别由观看任务决定。不得用统一中心构图、连续面部特写、固定镜头或垂直移动数量证明符合`portrait-v1`；每镜仍须有独立观看作用和真实来源依据。
- **冲突处理**：当必要来源信息与竖屏裁幅发生冲突时，先在已有事件内调整机位、前后景、纵深、焦点、切点或相邻镜头组合；仍无法兼容时记录具体不可兼容的主体、关系或动作阶段，不能为了通过检查改变剧情、删掉参与者或虚构新的空间条件。

竖屏配置不自动改变单元时长、镜头时长、镜头数量、声音估时或台词切分。作者和主审须把上述判断落实到实际提示词正文；机械检查只确认配置绑定、来源覆盖、时轴、引用和格式，不把词面出现当作竖屏语义通过。

## 摄影与空间

摄影须依据原文的叙事视角、信息变化和实际场面组织画面。先明确本镜必须读清的变化，以及承担该变化的可见部位、参与者和操作对象，再选择能容纳它们的景别、机位和取景范围。以实际裁幅核对必要的身体部位、道具、接触点和动作落点，景别名称本身不能证明它们已入画。随后确定相机路径、景深与光照，并回核切点和时长是否足以读取。取景与表演要求相互矛盾时，回改取景或当前表达，不能靠追加画框外的面部细节、光照落点或动作说明弥补。最终提示词的字段排列只是交付版式，不代表创作决策的先后。每镜应形成具体拍摄决定。工具不得按镜号、时长、标签、主角名单或模板回填固定、轻推、画外、接触或泛化景深。

每镜正文必须使摄影起点、路径、终点和切点可执行：起点是当前机位、景别和取景范围；有相机运动时，路径须写明起移时机、方向、速度或节奏、途中必须保留的主体关系及终点落点；终点是观众应读清的信息、动作或表演落点。固定镜头也须写明观察对象和切出落点，不能用“同前”“电影感”或单独移焦代替摄影决定。相机路径只服务当前观看任务，不得让人物等待摄影完成，也不得为走完路径拖长已经完成的动作。

### 叙事视角与信息组织

作者应明确当前段落让观众旁观场面，还是贴近某一人物的体验，以及何时转移观看重点。贴近人物体验不等于采用其眼睛位置的主观镜头，也不授权新增心理、感知或人物反应。视角可随原有信息与关系变化转移，不固定由主角或发言者承担。

信息揭示应区分观众何时得知、人物何时得知和事件何时发生。取景、遮挡、焦点与切点可以控制呈现时机，但不得改变原文明示的认知先后、事件因果或悬念结果。关系已经建立时应直接利用，不反复定场；尚未建立而影响理解时，应保留必要人物、对象、距离及方向。

同一镜头可通过既有动作、视线、构图和焦点变化承载多个连续信息；切镜应有转移观察、强化落点、接续动作或省略过程的作用。共同事件的可读标准是观众理解必要主体、变化和结果，不要求每位主体的全部操作细节各自清楚。遮挡影响必要信息时，先调整机位、取景范围和细节取舍；仍不能承载才拆镜，并保持事件原有时间关系。关键转折或复杂交互需要取舍时，应比较同镜呈现与切镜、固定与运动各自保留或失去的信息，再选择符合场面条件的方法。普通镜头直接选择，不逐镜列方案或填写理由表。

### 景别、机位与观看重点

不设景别权重、默认正面/45度、侧背比例、特写数量或焦段跨度配额。空间与时间对比可用远景/全景，肢体过程可用全景/中景，关系可用同框/过肩，具体表演、动作局部或关键信息可用近景/特写；它们是候选，不是题材固定拍法。对话不自动以说话者面部为焦点，既有听者反应、持物或关系也可承担看点。

近景不等于拍脸。面部主焦点的中近景、近景、特写均须有具体表演或有意义保持，保留视线对象和必要空间；正面拍摄不等于直视镜头。不要把重复正面机械改成重复斜侧，更换角度不自动解决表演重复。相邻同景别、首镜面部特写、合法正反打均可保留；连续三镜看点与摄影近似，或连续以正面面部为主时，核对是否仍有独立观看作用，失去作用才合并/重排，不强制插入全景。

| 选择维度 | 可选方法 | 条件 |
|---|---|---|
| 方位 | 正面、斜侧、侧面、背侧、背面、过肩、主观观察 | 根据实际视线、动线与轴线；纯背面不写眉眼，过肩需主体具备相应结构 |
| 高度 | 平视、轻微俯仰、较高俯视、低位、地面附近、顶拍、高位越肩 | 为看清动作和关系，不把高低机位自动等同强弱或服从 |
| 关系 | 双人同框、前后景、已有前景遮挡、动作局部、空间全貌 | 先有真实布局，不新增门框、栏杆、镜面或群体成员 |
| 关系尚未建立 | 双人中景、过肩、全景 | 保留需要辨认的双方和距离，已建立后可收窄，不每段重做定场 |
| 交接、接触、阻挡 | 侧向/斜侧中景、手部或道具局部 | 路径和参与者是新信息时保全，关系已清楚才可只取关键局部 |
| 信息落到听者 | 听者近景、说者作前景、同框中已有动作中断 | 反应有情境支持，不按发声顺序轮换面部 |
| 原有揭示/结束 | 推近既有信息、拉开原有空间、有效固定或相容收势 | 速度和展开服务原看点，收势遵守状态更新规则，不补无依据触发、额外事件或留白 |

原有交涉、对抗或主导关系的变化需要被观众感知时，应结合实际站位、视线、主体姿态和观看视角确定机位高度、画面占比及前后景关系。低位或仰拍、接近取景、对方前景和推进运动可用于强化已有关系，但不得仅凭狠话或情绪名称机械采用，也不得制造原文不存在的强弱结论。候选方法均需新增剧情才能成立时，应回到原看点重新选择；不能为使用某种摄影方法补造行为、道具或空间。

### 空间、构图、景深与光照

先以稳定场面参照确定实体真实位置、距离、持有、接触和朝向，再选择相机位置与观看方向，推导实际可见部位、裁幅及遮挡，由此安排前中后景，最后确定景深与光照。画面左右和前后景须从当前相机推导，不是固定场面坐标；人物“身后/面前”不等于相机前后景。正文将这些真实关系转换为可直接判断的画面方向或可见参照，不能把只有不同观看方向才能成立的画面拼进同一时刻。局部可见写实际部位；景深、虚化或光照不能让相机背后、裁幅外或完全遮挡后的部位进入画面。

镜头需要同时读清多个部位、物件或接触点时，先确认实际取景能容纳其位置与运动范围，再确定景别及具体摄影文字。需要读清的长物末端、地面接触点或其他远离主焦点的部位，须真实位于裁幅及可辨景深内。取景不能兼顾时，依本镜观看任务调整机位、裁幅或必要切点，并核对相邻连接，不能保留相互排斥的可见描述。

在场、可见、主焦点分别判断。保留画幅实际覆盖的关键参与者及理解事件所需的身份、位置和持续状态；换焦点、虚化、画外或遮挡不等于离场，画幅覆盖的区域不能无依据清空原在场实体。不强求所有在场者每镜露脸，允许相关人物处于画外，但须有可信的裁幅或机位依据；画内被挡住的部位按实际遮挡关系处理。画外目标只保留理解动作所需的信息，不叠加多层相对方位。集合称谓须明确所指范围，不得将某个行动组误写成场内全部人物。共同动作存在归属歧义时，以构图、空间分组和“动作执行检查”规定的持续活动区分参与者与非参与者，不靠反复否定句或默认逐人拆镜补救。

按实体关系保持180度轴线、视线及运动方向，换机位重新推导左右与遮挡，不复制前镜画面关系。运动镜头沿同一条实际相机路径检查起点、途中和终点的观看方向、可见部位及遮挡，不能只让两端构图各自成立。门扇、门框或其他已存在的遮挡影响动作时，先核实本镜必要的起始相位能否从实际机位看到，再按动作与相机各自进度检查露出时机，不能仅以终点无遮挡证明起始动作可见。来源允许省略的起始过程按实际切点处理，有意延迟的揭示仍按原有时机呈现。前景需持续在画面时检查相机是否会越过或将它带出画幅。接触持续时，裁幅和遮挡仍要容纳实际接触关系，不为构图补造分离、转身或位移。主体移动也不自动意味着环境相对固定相机后退。

每镜正文明确机位与运镜、构图、景深、光照，不能仅写“同前”“电影感”或拿抬头代替。同一有效机位、焦层与光照可以具体沿用，不强制每镜变化；沿用时以当前主体、清晰层或既有光向等必要参照说明，不从头重述未变化的整套布景和摄影安排。换机位、主体移动或关系变化后，须按新条件重新推导，不能沿用已失效的左右、遮挡或景层。空间描述只保留当前看点所需，不列全场实体清单；构图无法成立或取景负荷太大时，调整机位、裁幅或切点，再沿上述关系重新推导，不挤掉关键动作、表情或因果。

构图可选三分、中心、引导线、框架、对称、不对称、负空间，主焦点可在前、中、后任一层；留白不能让本应可见实体消失。景深指出谁/什么清楚、哪层稍虚并保留何种关系；真实接触承担看点才写接触点，注视、说话和挥手不自动存在接触。深景深适合需读多层关系，较浅景深适合局部，移焦适合已有对象间注意力转移，不与情绪或景别固定绑定。

焦段/光圈可作辅助，不必填数字，也不要求长短焦齐全。可写较广视角保留空间、较窄视角突出局部；具体数值须考虑镜距、成像方式和前后景距离，不能只凭焦段/光圈断言必然深浅景深或更强情绪。移焦起止与实际清晰范围一致。

每个镜头的光照描述必须写明当前已经成立的环境光照条件、主光方向、辅光/环境反射关系，以及它们在主体或道具上的明暗落点；当前取景无法辨认方向时，应明确写均匀、漫射或无明确方向的环境光关系。已经成立的环境光照条件只能来自原文、已登记资产或当前场景的物理必然性；没有明确光源名称时，应写环境光的方向、色温、明暗关系或对可见表面的影响，不得凭空补造灯具、月光、天气或发光事件。辅光、反射光、轮廓光、环境遮蔽和色彩溢出只在当前镜头确有作用时描述，但每镜仍要明确写出辅光或环境反射如何托住暗部、轮廓或道具；不能只写“光影自然”。连续镜头须承接既有光向、色温和强度；发生变化时，必须有当前可见的遮挡、时间变化、光源移动或场内事件依据。不得用“电影感光影”“高级光影”“氛围光”等空泛词替代具体光照。光照须与当前取景、动作和景深相容，用于帮助观众读清形态与变化，不能代替表演或动作。

### 运镜决策与速度反差

所有镜头均依据当前剧情节拍、信息转移、主体动线和观看体验选择摄影。单镜时长为5～6秒时，不得采用全程固定机位，须设计具有明确观看作用的相机位移或转向；运动完成后可稳定观察有效落点。1～4秒镜头先寻找能增加有效信息或提高可读性的运动方案，存在合适方案时优先采用；运动没有观看增益、会损害关键表演或空间可读性，或固定比较更清楚时，才选择固定机位。不得仅以“固定也能看清”为由放弃有观看增益的运动，固定也不是未设计摄影时的默认值。不因镜头短默认固定，不把情绪名称直接映射为推进、俯仰或抖动。摄影与时长须相互校准：缺少合理运动方案时，重排选定范围内已有内容与镜长，不以补动作、拖台词、无目的漂移或无意义微移满足形式；无法兼顾必要信息与约束时说明具体冲突，不自行放宽要求。

固定镜头应使持续观察、关系比较、原有表演变化或有意义保持可读，并有明确的观察对象、构图和切出落点。固定相机可以记录画内运动；主体静止时，相机仍可因信息揭示或叙事体验而运动。人物运动、移焦和相机位移或转向须分别描述，不能混称运镜。

运动镜头应明确开始移动的时机、方向、速度、起始取景、途中需保留的关系及终点。运动可以由既有动作、视线、信息或情绪变化驱动；运动本身不授权新增表演。一般一镜采用一个清楚的主运动，在信息应被读到的时机抵达有效取景，完成后可稳定观察仍有意义的动作或反应。运动所需时间依实际路程、揭示时机和可读性确定，不默认覆盖整镜，不因镜长5～6秒就把一次推进或转向持续放慢至镜尾；有意义的持续跟随仍按主体动线执行。连续运动镜头可以成立，各镜须承接实际节拍并产生自己的观看作用；不要求插入固定镜头。不得先用固定机位铺稿，再隔镜补运动以满足相邻限制，也不得按镜号奇偶、动静周期或比例安排摄影。不设移动量阈值、全段动静配额或交替周期；不得为打破统计规律补入无意义运动。

相机路径的起点、途中和终点必须属于同一条可执行路径；途中若不能持续保留必要主体、接触、视线或空间关系，应调整路径、取景或切点，而不是让动作停下来等待摄影。相机可以在关键变化读清后仍未完全停稳时切出，也可以抵达终点后短暂稳定观察，但两者都须有当前观看负荷支持；不得为了“完整走完运镜”补加无信息的缓移、回正或镜尾停姿。

叙事顺序上相邻的两个镜头不得均采用固定机位；此要求适用于同一单元以及跨单元、跨场的直接接续。判定以完整摄影描述中相机是否实际位移或转向为准：单独移焦、主体运动或切换到另一个固定机位，均不能作为相机运动。发现连续固定时，应依据观看任务调整相关镜头的摄影、合并或重排选定范围内的现有内容，不得删漏事件、增加无依据动作或以无目的漂移规避要求。指定范围与既有镜头接续时，应核对实际相邻镜头，不改范围外历史；确实无法同时满足来源与拍摄条件时应报告具体冲突，不自行放宽本条。

以下候选均须满足本节的镜长与相邻镜头约束，不因适用某种观看任务获得豁免。

| 观看任务 | 候选方法与取舍依据 |
|---|---|
| 读取持续状态或等待原有变化 | 先判断运动能否增加信息；没有观看增益或固定比较更清楚时采用固定观察，保留画内变化和有效落点 |
| 看清既有位移及其空间关系 | 跟随、转向、固定等待或切到落点；路程承担信息时保留，机械中段可压缩 |
| 逐步揭示已有信息 | 横移、转向、升降或改变取景范围；揭示时机须与原有认知顺序相容 |
| 改变关注范围或比较关系 | 推近、拉开、同框或移焦；依据应是具体对象和关系，不能默认推脸 |
| 接近某一人物的原有体验 | 固定凝视、逐步靠近或关系取景；按本段实际效果选择，不凭情绪名称套方法 |

运动速度应与信息读取和既有动作相容：相机应在关键变化发生时提供有效取景，不得让人物等待缓推、缓移或巡视结束才出手、命中或回应，也不得为完成相机路径延长动作。需要时可较快抵达取景后稳定观察，仍须保证起落和必要信息可辨；“运镜丝滑”规定运动衔接与画面品质，不规定动作缓慢、相机全程低速或镜尾长留。相机仍在运动时可以沿有效动势切出；切点须保持信息和空间可读，不要求每镜先把相机与主体完全停稳，也不为避免突兀而延长已完成的动作。静切动、动切静或同镜收住均可采用，不为组合增加镜头。甩镜、手持、倾斜、广角夸张、运动模糊、速度线、顿帧/冲击帧和时间重映射仅在风格与既有动作支持时使用，不扩大事件结果。

### 动作节奏与转场

日常动作只承担位置、持有或姿态转换时，应选取辨认变化及结果所需的有效阶段，可共同呈现、切入动作中段，或通过明确硬切、跳切、蒙太奇省略机械过程。承担因果、阻力、关系变化、揭示或表演转折的关键相位必须可读，不能只留结果，但不要求逐项展示全部准备与收尾。位移仅承担到达新位置的功能、中段可由前后可靠推知时，优先省略路程，不逐步展示完整行走。短拍1～2秒只是可用参考，不是路程或动作配额。保留理解接续所需的起点、方向和到达状态，变化及落点可读后直接接入下一项有效动作、发言或切换，不默认追加站定、背影保持、正面准备和无信息变化的完成姿态；原有等待或停步确有意义时仍应保留。时间省略须有真实剪辑落点，不能在同一连续镜里既“省略中段”又要求全程执行。蒙太奇、跳切和动作匹配只说明剪辑如何省略或接续过程，不自动证明机械中段已经省略；成稿仍须让观众读清来源支持的起因、关键变化、因果接触和结果。

快速攻击、突袭及瞬时变化须在正文中落实其发生时机和进度，不能只添加“迅速”“瞬息”等词后仍要求全镜缓慢完成准备、接近与命中。起势、接触、受力及结果按来源与实际机制保留必要相位；无依据的完整准备、机械中段、回正和收招应省略或与下一项相容变化接续。瞬时施力应及时转入相应受力结果，不把接触顶点写成长时间贴住或悬停；持续推压、抓持、角力等按实际机制判断，不能为节奏统一改成短触即离。前镜已完成的准备和结果不得因切镜再次展开；同一触发的反应按共同事件时间接入，不排成逐人等待完成。快速动作后的必要结果可以继续观察，但动作已完成且没有新信息、表演变化或必要辨认任务时，应切出或接入下一项已有内容，不能以“保持姿态”填满余时。不得为提速改变攻击次数、接触、因果、结果或来源已有的悬念与停顿，也不把打戏一律规定为2～3秒。

短暂示意动作在对象、方向及回应关系可读后，应结束该次展示或进入下一项有效变化，不因镜头尚有剩余时间而延长、循环动作或等待摄影逐人巡视。收势与下一项发言或活动在身体条件、接触及因果上相容时可同期接续，不默认依次经历“动作结束—完全停稳—准备发声—开口”；必须先完成的解除约束、换气或交接仍按实际条件保留。原文指定的小幅、轻柔或克制只约束相应维度，不自动延长动作时间；力度、阻力与速度分别判断，不把沉重、有力或缓缓一律写成全程匀速迟滞。动作有来源支持的起势、接触变化和收住按实际机制形成速度变化，有意义的持续示意和原文明示慢速仍按原情境保留。情绪氛围动作按原变化安排，不自动慢演、压短或拆微动作。省略后仍应理解起因、变化、结果及情感，丢信息就恢复对应点，不拿转场名称掩盖遗漏。

切点必须同时说明前镜从哪个可读相位切出、后镜从哪个相位接入，以及切换要保留的动作、视线、信息或反应关系。切点可以发生在相机仍在运动、主体动作仍在进行或结果已经读清之后，不以相机完全停稳、人物完成全部收势或镜头时长结束为前提；但不得在关键动作、接触、表演变化或必要信息尚未可读时切走，也不得因等待摄影或避免突兀而延迟已经完成的事件。动作匹配、视线匹配、声音先行或其他转场名称只能说明连接方式，不能替代前后相位、真实锚点或省略依据。

镜间转换应先确定连续动作、观察对象转移、反应呈现、时间省略或叙事层变化等接续关系，再选具体切法。切点应落在可读的动作进展、信息识别、发言语义或原有反应上；不得在必要信息尚未被看清时切走，也不得无意义地延迟切换。当前构图可以完整承载下一步变化时，可继续本镜，不因换发言者或进入新句自动切镜。转场名称不能替代动作完成点、并行关系或省略依据；写有“动作匹配切”“声音先行切”“叠化切”不等于已经压缩了无意义过程。

同一动作连续跨镜应写明进度、方向与落点，并承接影响理解的运动方式、受力与支撑关系；换机位时重新推导画面方向，不把画面左右当作世界方向。动势延续或有可读的速度变化依据，已完成的不重放。受力滑行、倒飞、坠落等被动运动在未发生有效支撑、阻挡或自主恢复前不得切成主动奔跑、站定或重新起势；“尚未稳住”等否定描述不能代替当前身体姿态、运动方向及接触条件。再次追及、接触或施力须作用于对方当时仍成立的运动状态，不能为复用前一动作构图而重置双方。动作匹配应在同一动作进行中切出并从对应阶段接续到结果；前镜已完成、后镜新动作且无锚点时用普通切法。视线、形状、位置或声音匹配应有真实共有锚点；硬切是画面切换方式，可与匹配依据组合，不等于缺少叙事连接。

连续穿越、碰撞及其后续位移须让观众辨认事件仍在进行。若后镜继续同一次运动，前镜切出应保留可辨的出口动势或方向锚点，后镜入口承接对应相位；可以同镜连贯呈现，也可以在必要接触或结果可读后切换。尘雾、碎屑、闪光等遮挡不能替代关键主体的因果轨迹，不得在主体消失后长留局部破坏或完成姿态，造成已停在此处的判断，再无依据地恢复运动。确需遮挡或省略机械路程时，遮挡前后的主体、运动阶段及相对空间须足以连接，不要求全程露出主体；来源明确的停顿、观察破坏结果或转移关注仍可成立。主体出画且去向已读清时，应接入下一项有效内容或结束本镜，不默认追加空景尾段。

取景和切点应考虑观众前镜的主要注视区域及后镜需要首先识别的内容，使注意力延续或有依据地转移；不要求对象保持同一画面坐标，也不以“匹配”名称代替实际方向、相位或对象关系。可使用既有前景遮挡、轨迹及适用的甩镜或闪白闪黑，不为转场新增实体或特效。

原文明示叙事层变化才采用相应色彩/清晰度/光学过渡，不固定梦境或回忆色调；主观机位按实际感知，不默认暗角晃动。时间静止须原文许可。已明确将发生且传播合理的闪光/震动可影响前镜末尾，不预演不存在的爆炸或提前结果。

以下仅说明取舍方法，不预设实际项目的事实或固定拍法：

- 静止对话：可保持同框观察原有反应，也可在话语作用落到听者时切向听者；人物未走动不构成必须固定或必须切面的理由。
- 身份揭示：按原有认人顺序连接视线、被识别对象与已有反应；转向揭示或切镜均可，不提前泄露身份或补造惊讶动作。
- 移动与碰撞：跟随或固定取景先交代原有路径与阻挡，再按同一次接触相位切到结果；路程可以省略，关键因果和碰撞次数必须保留。

### 慢速表演与时间表现

区分故事中实际缓慢的行动、必要等待和影像对短瞬间的慢动作强调。前者按来源的真实时序与表演保留；后者只在风格和既有事件支持、且能突出具体接触、变化或辨认任务时采用，不自动套用于整段动作。没有慢动作说明也须检查正文是否因长时间停姿、迟迟不接触或迟迟不转入结果而产生无依据的慢演。

采用慢动作或时间重映射时，正文须交代所强调的动作阶段、进入时机与结束条件，并使退出后的运动和结果清楚接续。起止由既有接触、形变、信息被读清或下一相位接入确定，不为达到镜长持续延长。必要时可在整数镜窗内用自然语言表达短暂强调后恢复正常速度，无需新增小数时码、倍率字段或计时表。完成强调后仍有未尽观看任务才能继续慢放；相邻镜头和连续动作须合看累计效果，不能无观看依据地每镜各自强调同一冲击、把接近、接触、飞行和落地逐段全部拖慢，或以慢动作结束后的长时间停姿再次稀释结果。

影像慢放不得新增故事时间、反应机会、攻击次数或结果；主观时间、时间停滞及其他改变故事机制的表现须有来源依据。冲击力可由原有动作的速度变化、短促接触、受力后果及有效切点形成，不以慢放或凝固接触作为默认表达。明确的持续角力、原文慢行、情绪观察、悬念等待和其他必要长时过程仍按其观看任务保留。上述判断适用于不同题材；不设统一慢动作秒数、比例、必用次数或全段短镜配额。

### 参考有限时与空间示例

参考图说明身份和结构，不决定本镜表情、姿态、持有者或场面人数。空布景不表示场面无人。个体板的面部及正侧背参考须实际存在清晰；群像板各成员正面全身不等于同成员侧背参考。遮面造型只写露出部位，不能穿透遮挡；群像样本人数不限定剧情人数。

角度参考不足可选择保留同一叙事信息的过肩/背侧、已有遮挡、原动作局部、可支撑的高低位或全景；反射面必须实际存在且方位可信，可能增加一致性负担，不作默认补救。大幅环绕、显著侧脸和面部特写核对实际支撑，不用焦段/角度阈值保证质量。无图可继续规划并标待补，不自动生图或阻断空节点；只有核心信息无法可靠表达才提出具体补图需求。

以下为虚构空间推导示例，不为实际项目增加事实：

- 两人隔桌对坐，已定甲西乙东、南侧可架机：从甲后侧偏南朝乙拍，甲肩背是前景、正脸不可见；反打仍在轴线南侧，重新判断左右和遮挡，不复制背景或给背对者写眉眼。
- 停稳车内甲在驾驶座、乙丙在后排：从前排中央朝后取景时，乙丙可同框，甲在机位后方仍在场；不删甲、挪座或因后排一人近景认定另一人离场。
- 甲右手递唯一信件，乙左手接住后甲松手：桌侧斜向取景保留双方手与路径，景深读清实际接触；后镜是乙已持信，不能再交一次或让甲留第二封。关系未建立时先用可读同框，不靠孤立局部补事实。

## 连续性


区分同时成立的状态与发生变化的事件，原文罗列顺序不自动等于时序。分别判断在场、可见和主焦点：虚化、遮挡、换焦点或取景外不等于离场。根据真实空间和相机起止取景决定画面层次，不把画面左右直接当场面位置。

同一人物/物件保持同一身份，人物形象版本不是多个同时在场的人。普通同款实物确有多个时才按来源区分；已登记图片资产不能被临时别称替代。参考图提供身份与基础结构，当前剧情中已发生的衣装损坏、形态改变、物件缺失等有效状态须在后续适用取景中延续，不因换镜或重新使用参考图恢复默认完好外观；真实修复、替换或时间变化按来源更新。只追踪影响理解的事实，不发明坐标、姿态或心理，不要求非人形主体具备人类身体结构。

场末用一小段普通文字保存后续确实会用到的持续事实，包括仍在场的主体及当前形象、重要物件的持有者和必要携带状态、后续仍成立的位置或接触、未结束的动作进度及环境状态。只记适用项及尚未解决的问题，不重抄全场，不保存逐镜快照或固定键值表。真实跳时或转场后，用新场原文重建变化部分，仍有影响的持物和身份继续核对。

### 既有物件的常规携带与收置

前文或有效已审末态已经确认主体持有某物件，后续连续剧情未给出转交、遗失、消耗、损毁或其他终止持有的依据时，物件继续由该主体持有。中间场次未提及该物件，不要求保持原操作姿态，也不要求持续入画。写者可根据主体实际结构、物件尺寸及既有承载条件，选择低调随身携带、自然垂持、挂置或收纳等常规状态。

这种处理须保持物件身份、数量、持有者及已成立的损伤、功能和取用条件，并与当前动作、空间及后续情节相容。所选承载或收纳方式须由既有形象、结构或环境条件支持，不为方便连续性新增容器、挂载装置、储物能力或其他机制。不存在相容收置条件时，采用可成立的携带方式。判定依据是本次动作的实际条件，不按题材、物种或物件类别预设人类手部、腰带或口袋。

常规姿态调整、收置和再次取用，在不承担情节信息、不改变关键接触或操作结果，且有相容时间与行动条件时，可在合理剪辑省略或画外过程内完成。后继镜从已经成立的当前携带或取用状态接入，无需逐场补写收放动作或新增说明镜头。当前画面确需辨明物件关系时，正文表达本镜可见的状态。若占用解除、取用难度、隐藏或暴露、交接、危险控制等本身影响行动条件、人物认知或剧情因果，应呈现必要过程并承接其结果。

再次参与关键动作时，核对物件身份与此前持续状态，并使本次起始状态和动作过程可执行。来源明确要求持续握持、承托或操控，或后文与原持有关系冲突时，按来源与实际影响处理，必要的身份或因果疑问仍交用户选择。此规则提供常规制作选择，不将省略的收置过程登记为原文明示事件。库内既有道具缺少本场引用关系时，按[文本接口的跨场道具引用](storyboard-text-format.md#文本分镜接口)记录持续关系和依据，沿用原稳定ID。资产身份、来源或台账本身确需改变时，按[绑定变更边界](binding-changes.md)处理。

### 状态更新与关联修订

持续事实和瞬时阶段分开。身份、持有、支撑、操控及持续接触在条件未改变时承接，物件的持有关系与具体携带姿态按上一节分别判断。示意、指点、挥手、受力顶点或动作中间姿态，不得仅因后文未写结束而延续到场尾。短暂动作达到其作用条件，或因中断、约束变化而结束时，应进入与原结果相容的收势、稳定或续行状态。写下一镜或单元起点时，只继承仍有效的事实，不把一次抬手永久复制为“手一直端着”。承重、操控、安全或关键接触仍依赖某一部位时，应维持真实占用，只有满足来源及常规收置条件后才可调整。未改变剧情结果、关系及重要接触的常规收势，可作为动作完整性的一部分具体化，不要求原文逐字写出。来源明确要求保持、保持本身承担信息或结束会改变结果时，仍须保留相应约束。持续接触的结束须有来源依据或满足上述常规状态调整条件，不为补收尾新增决定。情绪反应按已达状态承接，切镜不重置表情或重演同一触发。短暂变化收回后不自动延续到场尾，仍成立的笑容、面部张力及汗泪状态不得无依据消失。

同一位置不能代替同一状态。换机位或重新入画时，已经成立且影响当前画面理解的持有、支撑、操控及接触关系，应落实为当前取景可辨的正文。只写座位、站位或“仍在原位”不能视为已表达相应关系。下一镜或单元起点承接前镜实际切出时已达到的末态，动作尚在进行时按其真实相位接入，不能提前写成预期完成姿态。只保留仍成立且影响理解的部分。

主体或参照物的位置、姿态、持有、接触、形态或在场改变时，判断相关关系是否仍成立；不要只改主体还保留失效相对位置或接触。接触、指向和注视写清执行者、目标及必要部位归属，换机位不能换人或转指摄影机。跨镜承接同一事件的已达相位，不重复起势或触发；先前已完成的动作不得无新依据再执行。

同场已核实的身份、空间结构、光照条件、持有及持续关系，在来源和相关版本未变、当前事实仍成立时直接复用。后续镜头读取当前原文和必要连接，按实际变化更新相关判断，换机位后仍须重新推导可见性与画面方向。动态环境状态不能回到参考图的默认时点。影响当前行动的环境事实按当前事件判断有效范围和先后，不能无限延续早先状态，也不能凭空消除障碍让动作成立。

修订在发生变化处改正文，同时检查实际受影响的动作、摄影、构图、景深、光照和可见描述。旧事实残留可用文字检索定位，但词语出现/消失不证明语义一致。检查沿真实影响到重新一致的位置，不编造 reset，不建依赖边来替代阅读；无关镜头不重审。该判断融入书写和改后连接复看，不另开状态前检。

### 形象与声音

source-masked-v1 项目的同一人物按原文戴上/摘下事件切换已核实形象，不能提前、漏掉或把转换截在单元边界。前后版本引用必须明确属于同一主体，正文表达实际转换及当前状态，不将参考版本并列为新增人物。参考图固定身份和结构，不将其中的中性表情、姿态、动作或环境锁定为全场状态。

声源身份与画面形象分别判断：现场人物用当前合法形象；同一句跨摘戴、内心想法os或画外音发声时，保持原声源和原话，并检查标签是否误导画面。不凭声音标签强迫入画、不让听者代说，不把画外发声误写成离场。来源中的`os/O.S./内心OS/内心想法`统一按内心想法os处理，`ov/VO/V.O./画外音`统一按画外音处理。

```text
·T1秒-[单元时长]秒[镜头2-叙事标签]：（[主焦点景别]；转场：[具体切法]）[机位与运镜]，[构图]，[景深]，[光照]；[本镜行为及可承接落点]。[必要声音]。音效：[有依据的音效，无则无]。
```

以上变量和省略说明不出现在成稿。镜数动态，时码为两位整数秒如 `·00秒-03秒`，连续覆盖总时长；镜号从1递增，末镜终点等于总时长。单元4～30秒、单镜1～6秒等规则见[声音与时长](#声音与时长)，不固定11镜或30秒。

分段编号和新轮后缀只按[范围定位与历史检查](storyboard-workflow.md#范围定位与历史检查)分配。首轮或未拆分项目无新轮后缀；同一重做轮次的全部单元使用相同后缀。每份新交付TXT最后一行由导出程序汇总为“本次共x个分镜单元，总时长 x1分 x2秒”，x为本文件单元数，时长为这些单元的秒数合计换算；不统计镜头数、不累加历史版本。这一行只属于完整TXT，不写入任何单个视频节点提示词。

### 正文表达

场景行只列 SET 完整资产名，不输出标准场景 heading；heading 仍用于后台定位。之后独立“人物站位：”，写本单元真实起始关系，不另写全局光照、构图或氛围行。仅画外发声者按实际情况注明，不强迫入画。

每镜括号只放主焦点景别和具体转场，不加“景别：”前缀。机位与运镜在括号外，随后构图、景深、光照用中文逗号连接，再用分号接动作。摄影条件明确，不能只写“同前/同上/无/电影感”；继承时说清保持什么。不为填照明内容新增灯具、火光、月光或天气。构图说清实际前中后景，人物“身后”不能代替相机层次。每镜必须让主焦点、动作执行者、可见参与者和在场/画外状态可区分；不得用“不同景层保持可见关系”“后景人物做有意义反应”“当前道具”等抽象占位替代具体位置、对象、视线、动作和反应。

主焦点与其他参与者分别表达，群像可共同成为主焦点；原文支持的无人环境镜可用环境景别，不补人物或道具。焦点的关键动作过程和可见表演直接写正文，相关参与者按情境回应、继续或有意义地保持；不增加全员动作配额。不可见表情、抽象“情绪可辨”或后台分析不能替代必要信息。


叙事标签贴原动作或情绪落点，不固定建立—推进—爆发。转场写确定切法，不给“如/可/或”备选。动作匹配交代同一动作切出/接续相位与真实锚点，只完成一次。多动作压缩用明确硬切、跳切或蒙太奇。视线匹配说清对象与方向，不把普通切换泛称匹配。连续硬切或统一转场骨架只提示独立主审核对实际连接，不因数量或种类自动退稿，也不要求为统计补写解释。只写转场名称而使必要前后相位、锚点或省略依据缺失时，须修正实际正文。

每镜以 `音效：` 收尾；多个有依据的声音用 `+` 连接，需要先后时在该字段写明随何动作发生或何时接续，只有一项就只写一项，无适用声响写 `音效：无。`。不在正文重复同一音效；来源明示的发声方式、群体齐声、口哨、号子、脚步、马蹄、兵器和接触声不得被统一压成“环境声”，必须在实际声源和动作相位中落实。必要动作/视线/构图连接自然并入正文，不另起“连接词”行。连续性用当前状态和实际动作表达，仅用于提醒作者避免重复、解释审核或排除无关错误的否定句留在内部记录；具有剧情意义的拒绝、未完成、中止和有意克制仍按实际画面表达，不按否定词机械删句。成稿不附规划、状态表、自检、时长分析、AU/强度评级、资产解释或规则判断说明；动作表情只用本文件“表演与动作”规定的可视化表达。

### 图片名称与声音

- 需图片的人物、布景和主要道具在引号外使用 `@台账完整name `，名称后有英文空格。人物站位行中的主体、持物者、接触对象和方位参照，以及镜头正文中的关键执行者、目标和跨镜重新建立的关系，均须使用当前有效形象或道具的完整引用；不能仅依赖单元名单、景别括号或用单姓、人名截断、临时简称、代词推定身份。主体切换和多人多物交互时明确相关主体与目标；已绑定主体的同句部位承接可简化，但不能产生归属歧义或另造简称。无需图片的prompt_only主体使用台账完整名称，原台词及原声源称呼逐字保留，不因本规则改台词。人物行逗号分隔、末尾一个分号，无人为 `人物：无；`。形象后缀保持台账原名，不重复 name@name。
- 母稿的非对白资产引用使用已核实 `@{CHAR0001}` / `@{SET0001}` / `@{PROP0001}`，由脚本生成完整名称；不要在母稿另手写显示名引用。SC是剧情场次，不是图片ID。不做简称/别名的无边界全文替换，不改原台词中的名称。
- 实际画面主体、发声者及交互对象按其已登记身份和现有协议进入对应名单或引用，保持正文、声音与声明一致。纯语言提及或尚未安排为实际画面的想象内容，不因出现名称就强制增加资产、出镜者或名单。来源明确要求呈现的叙事层仍按实际画面核对身份和引用。
- prompt_only 群像用普通完整名称、不加@；仍作为有人镜头处理，不因没有图片引用消除其实际参与。经复核的非人物播报用普通来源标签，不新增人物资产。
- 场景多叙事层按出现顺序列合法布景；日夜、天气单列，无天气依据写“未明示”。标题默认日只供时间表达，不冒称原文明示事实。
- 新文本回执使用 none-v1：不添加黑幕ID、节点、连线、素材检查或提示词标签，不增加黑屏镜头和时长。历史黑幕模式仅按旧receipt兼容。

现场用 `@完整人物名 说：“原台词”`；新`scene-text-v1`输出的内心声统一用“内心想法os”，作者稿中的`os/O.S./内心OS/内心想法`均按该类型解析；作者稿中的`ov/VO/V.O./画外音`均按“画外音”解析。普通括号提示只写本片段必要的声音表现并逐字保留，不得与声音类型别名混淆。旁白用已核实人物名加“旁白”。非人物播报用 `原声源名非人物播报：“原话片段”`。不凭设备名称自行分类，不将内心想法os/画外音交给画内听者代说。

必要声音表现放在发声标签后、原话引号前，例如 `说（音量：压低音量；尾音：短促收住）：“原台词”`；常规中性表达可省略括注。声音内容不写进原台词引号或音效栏，可见动作和口型写正文。表现选择及跨镜继承按本文件“声音与时长”。

母稿中 `声音[L000007,0.2-2.8]：…` 等来源/时码标记仅供机械校验，导出移除标记并保留发声标签、语气与原话。每片段须在本镜内，原话逐字拼接一致；分片与声音结束后的画面接续按[镜长与声音安排](#镜长与声音安排)执行，不因交付格式改变切点或拉长句尾。

### 命名与交付

已确认拆分方案的项目按[分段及轮次编号](storyboard-workflow.md#范围定位与历史检查)使用分段字母；局部范围延续本段当前轮序号，整段重做使用新轮统一后缀。未建立拆分方案的项目按同一聊天成功提交次序使用A、B…Z、AA，批内序号从01开始跨场连续，每场展示分镜号从1起，例如`B01-场景1-分镜1`、`B02-场景2-分镜1`。两种策略均由脚本分配并保存内部累计稳定ID；重试、重导出和指定局部修改保留原名。标题追加时长和已冻结比例，视频节点名只用展示名。历史显示格式原样读取。

新任务的正式TXT由commit写入项目work的不可变版本目录，主代理按[输出保护](execution-contract.md#本地调用与输出保护)将该段当前最终版按原字节发布到outputs。每段发布一份稳定文件名的TXT，过程`-r`修订与旧版原件保留于work，不在聊天粘贴全文。交付仅报 `本次生成分镜共N个，总时长x分x秒。` 和链接；修改用“本次修改”。N为本次单元数，总时长只计本次，不累加历史，不足一分钟仍写0分。正式编号和提交由主代理单写；预览不占用编号。

旧 reference-v1/v2/v3 JSON 的字段与渲染兼容由[历史回执兼容](runtime.md#历史回执兼容)及脚本维护。本文件的文字路径不要求 focus/subjects/purpose、摄影字段对象、continuity 或逐镜证据，旧字段名也不输出到产品提示词。
