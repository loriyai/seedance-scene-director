# 分镜重构移除与归并记录

适用版本：v0.19-local.1。本文件集中记录本轮退出新稿路径的机制、去重位置和兼容边界；它是维护记录，不供作者执行。原完整版本保存在本次安装外备份中，可据文件路径恢复，不把旧全文复制成另一套活跃规则。

本次新入口为scene-text-v1：直接维护提示词正文，范围简报一次，当前场短节拍，作者同次书写检查，一次独立整场阅读，集中修改后复看真实影响。脚本只做确定性校验、身份/编号、导出和事件计时。旧脚本文件保留，退出新路径不等于已从包中删除实现。

## 旧缺陷与兼容边界

已知旧问题PROD001位于scene_review.py的verify_reuse_evidence警告比较：`warning_keys == evidence['reused_warning_keys']`按列表顺序判断。此前实例中当前52条警告里的19个复用键集合、处置及依赖未变，跨进程排序差异仍触发“场次复核：复用警告及依赖已变化”。**本轮未修改这个旧gate，不声称该bug已修复。**新文字路径不调用这条复用链，因此新交付不受该检查阻塞；明确继续旧流程仍面对原实现。

不静默迁移真实项目、历史session单元、资产、设计、receipt、Canvas节点或暂停队列。文字回执存入现有session并共用正式编号分配器，旧receipt保持原导出；用户明确选择的旧单元可通过新路径精确替换，范围外历史保留。脚本的内部派生缓存不是第二份作者输入，也不得人工维护缓存代替修改正文。

结构与离线测试只验证可计算约束；场级报告依赖实际独立阅读，程序不能证明阅读发生或视频执行成功。本记录不承诺未测量的速度提升，也不把绕开旧gate描述为修复旧实现。

## 分镜规则

- 只使用通过检查的标准剧本，人物、场景和主要道具采用资产台账名称；当前范围的关键物件反查候选审阅，发现缺少必要参考时先完成相关资产复核，不能因未入台账而跳过。
- 26～30秒为优选范围，不是硬下限；自然动作/语义完成时可用4～25秒，后台记录依据，不补动作填时长。
- 29～30 秒默认建议 11 镜，26～28 秒默认建议 9～10 镜；为自然表达可调整至 8～13 镜。不足 26 秒的单元按内容安排镜数。
- 单镜头为1～6秒整数，各镜头时长之和严格等于单元总时长。1～3秒可以固定或运动，须按观看重点、动作路径、信息揭示及剪辑承接明确选择，不得默认固定。固定须说明稳定观察的具体作用；运动须明确方向、起止取景与落点，且在当前时长内可读。缺少选择时标记待补，辅助程序不得回填固定或微动。固定仅限1～3秒；4～6秒必须有服务观看重点的实际相机位置或朝向变化，仅移焦、主体运动或笼统运镜词不算。
- 连续段落须在现有作者前检及独立审阅中比较相邻镜头的观看任务和摄影选择，避免因景别或主体不同遗漏重复问题；时长与动静分布只用于定位复核，不设固定/运动数量比例。运镜修改同步核对构图、景深、光照、可见范围与切点，不增加审阅轮次或必填表单。
- 按当前情境中的动作作用安排节奏：机械过渡优先短镜、合并或省略非关键中段；情节关键动作保留关键行为与结果；情绪氛围动作保留原文变化与必要停顿，不默认慢演。动作匹配在进行中切出、后镜接续，整组只完成一次；画面压缩不改写标准剧本。
- 表演按实际可见程度选细节；原文有转折才写触发后的弧线，听者不虚构心理，关键动作按需核对接触、路径和落点。机位与微动词库提供选择，不得仅为增加变化而逐镜更换角度或添加微动作。
- 新有声单元使用event-inheritance-v1：必要持续表现写audio.delivery，片段变化或恢复中性须有依据；现场声、内心声、画外音和旁白采用同一标准，无明确表现需要时不增加声音修饰。语速统一来自audio.speed，非默认语速独立输出。旧receipt保留旧策略；变化后重新核对时长、口型与连续性。
- 台词、说话人及发声类型以标准剧本为准。短句完整放一镜；长句按标点和语义分到各镜，每镜写实际台词部分。估时仅存后台，不按时间比例切字，不用抽象续声说明。
- 景别、主焦点、机位与运镜按本镜剧情看点选择，不设固定景别权重或默认正面/45°机位。新提交逐镜填写后台purpose说明依据；近景/特写数量、相邻与首镜面部限制改为审查提醒，检查重复画面和连续正面脸部镜头（含中近景），不得仅为满足比例或避开提醒而更换角度。
- 新生成或指定修改使用reference-v3：场景行只列布景资产名、时间与天气，不输出完整heading；其后独立写人物站位。每镜以括号包住主焦点景别与转场，括号外依次填写机位与运镜、构图、景深、光照。旧reference-v1/v2及更早交付保留原版渲染。
- 新范围按同一聊天依次分配A、B…Z、AA批次，批内从01跨场连续编号，名称末尾的分镜序号在本批各场景分别从1计数；TXT标题如`A01-场景1-分镜1（时长：18秒）`，视频节点同名但不加时长。重试和局部修改保留名称，后台稳定ID保留，旧receipt保持原显示方式。
- 资产阶段完成群像地点后缀、同名道具视觉复用、角色世次/形象启用及唯一名称预检。背景群像按复用或核心连续性两条路径审阅图片需求；文字已足够的群像保留剧情登记并用普通文字进入分镜。群像图片仅固定制作外观，不负责人数、队形、站位或动作连续性；需要具体成员辨识时核实为独立人物。分类视觉描述分别使用角色01、场景01、道具01编号。原文用词与制作名独立，道具图片复用不合并实体数量；形象切换须以原文事件的实际发生位置为依据，预示或身份识别本身不构成切换证据。
- 分镜中纯文字群像成为至少2镜的主体或任一镜主焦点时，提示复核图片需求；覆盖完整已审出场证据却未登记该群像时，提示复核画内/画外参与。两镜不是两次独立事件，也不自动升级资产。已确定需要图片参考的群像不能以精确名称或显式别名改登记为空asset_ids的临时实体；共用一句原文不用于判定实体身份。
- 不得为达到建议时长新增动作、重复事件、放慢台词、循环动作、空镜或无叙事作用的停顿。
- 视频风格为变量；新提交和选定替换使用visual-only-v2纯视觉抬头，音频仍由逐句及逐镜字段表达。旧receipt与历史冻结任务按原抬头渲染，不自动迁移。
- 后台完成规划、估时和自检，分镜提示词写入交付 TXT；对话仅展示文件链接、当前批次数量及总时长和必要菜单。

默认提示词规划入口采用整数 4～30 秒；实际使用入口存在其他合法档位时，应按入口配置检查。此 Skill 生成提示词，不直接生成视频。

## 单元字段

新生成和指定替换的单元须填写`continuity`：

```json
{
  "version": 1,
  "boundary": {"kind": "continuous"},
  "entities": {
    "person": {"asset_ids": ["CHAR0001"]}
  },
  "initial": {
    "person": {"present": true, "asset_id": "CHAR0001", "facts": {"位置": "门内", "持有": "空手"}}
  },
  "final": {
    "person": {"present": true, "asset_id": "CHAR0001", "facts": {"位置": "门内", "持有": "空手"}}
  }
}
```

- `boundary.kind=continuous`继承来源相邻单元末态，包括换机位后仍成立的实体关系。实际时间、地点或叙事层跳转可用`reset`，必须同时填写非空`reason`与`evidence`；不能把常规切镜当重置。重置后的进入态依据新场原文及有效上下文建立，未继续记录某项旧事实不等于证明该事实已经结束；不得据此补造状态转移或实体去向。仍决定当前动作的必要事实须核实依据。
- `entities`以稳定实体ID为键；已建资产仅填写`asset_ids`（CHAR/PROP ID数组，可包括同实体的不同形象，但不得混合人物和道具）。只在画外的已登记实体可以不列入本单元`character_ids`/`prop_ids`。
- 原文支持且按现有资产规则不需建图片资产的临时物件、空间参照或环境状态，填写`{"asset_ids":[],"label":"名称","evidence":[{"record":"L000003","quote":"原文逐字片段"}]}`；`asset_id`为`null`，不进入资产subjects，不由此新增资产节点。实体存在依据可引用本单元末尾之前已经到达的原文，允许承接早先建立的实体，不要求每单元重复出现名称，禁止借用后续原文。仅作关系描述的空间参照可写在facts值中，不强制独立登记实体。不得把已登记人物/道具改成空asset_ids绕过引用，也不得通过后台元数据新增未经原有身份流程处理的人物或群像；完整名称的直接冒用会拒绝，别名或身份关系仍须人工核对。
- `initial`和`final`恰好包含全部登记实体。每项为`present`布尔值、当前`asset_id`和`facts`对象。`present`表示实体在当前叙事场面内，画外在场为true，远处画外声源可以为false。`facts`使用必要且稳定的关系或状态键及非空字符串值；仅无相关关系/状态需要追踪时可为空对象，不用空对象绕开必要检查。不把画面左/右作为真实场面位置；相同事实沿用同一键和值，不改换同义词制造或绕过变化。
- `final`必须等于从`initial`逐镜重放变化得到的结果。不变事实自动继承，不逐镜复制完整快照。

每镜须填写`continuity`：

```json
{
  "changes": [],
  "visibility": {
    "person": {"mode": "visible", "basis": "人物上身在门内构图中可见"}
  }
}
```

- `visibility`每镜恰好覆盖全部登记实体。`mode`为`visible`（包括部分可见）、`offscreen`（在场但取景外）、`occluded`（完全被遮挡）、`absent`（本镜全程不在当前场面）；每项`basis`具体解释可见区域或取景、遮挡、离场依据。虚化但能确认人物存在仍为`visible`。
- 先根据机位起止取景与真实位置判断可见性，再填写subjects；不能因为没有列入subjects就自动标画外，也不能把label重复成空间依据。取景覆盖多个实体或发生运动时，核对相机所在侧、既有空间边界及运动过程中的遮挡。必要的关系落实到composition/text，后台basis不替代最终镜头表达。
- 可见注册资产须列入本镜`subjects`；`subjects`每项须有对应可见实体，`focus`不能指向完全遮挡或画外实体。仅声音参与者写`audio`。允许同一镜内进入、离开或变化形象，不要求焦点在镜尾仍在场。
- `changes`按发生顺序登记源于原文的变化：`{"entity":"person","set":{"facts":{"持有":"信件"}},"evidence":[{"record":"L000004","quote":"接过信件"}]}`。`set`只更新`present`、`asset_id`、`facts`；facts逐键合并，值为`null`删除已有事实。不变内容不登记为变化。
- 每次变化及局部实体证据使用`[{"record":"标准正文行ID","quote":"逐字引文"}]`。事件变化及重置的引文必须位于本单元实际选定的行内片段，不可借用同一行尚未选入的后文；局部实体的存在依据另允许已到达的前文。引文只证明来源存在，不证明语义解释成立。
- 边界重置也可以引用本单元场景标题：`{"kind":"reset","reason":"原文转到城门","evidence":[{"scene":"SC0002","quote":"场景2-日-外-城门"}]}`。所有reset返回人工复核提醒，确认原文确实支持重置。初始选定范围没有已知前序时可直接使用continuous，不杜撰前史。

## 约束顺序与落点

新B流程在排摄影前使用[声音前检](scene-review-workflow.md#身份与声音前检)：先确定实际读法、发音单位、片内停顿和片段间隙，整句单位与总停顿由同一份计划核算。仅将确定的登记或计算矛盾视为阻塞错误；语速、长气口及自然分句仍依原文实读。不要为了消除估计警告补停顿或拉长尾字。

起草前按[关键触发、时间窗与渲染前检](scene-review-workflow.md#关键触发时间窗与渲染前检)提取本场少量影响因果的必要先后，在既有action_plan/audio_plan中先确定触发、动作窗口与起音，再排摄影和切镜；同期事件、因果先后与剪辑呈现顺序分别判断。同一事件跨镜呈现时以同一原文来源锚点确认事件身份，按实际时间关系承接事件进度，说明各镜承接的过程或结果，不因切镜重新发生动作、触发或声响。仅为影响理解的必要动作安排窗口，不为所有细节新增记录。冻结前实读同版本渲染稿及后台时码；purpose保留判断依据，不能代替提示词中可读的触发、动作先后与一致状态。状态结束与参照关系变化按[状态更新与关联修订](continuity-state.md#状态更新与关联修订)处理，不因状态结束自动新增动作、心理变化或反应。

范围与节拍分析按上一节完成，不在进入每镜时重新从头分析。全程遵守资产及状态连续性规则。方法和词库不能授权新事件，不能改写固定抬头文字、reference-v3结构或semantic-v2对白保真。原文要求持续平静或静止时允许保持，不为了表情弧线制造起伏。视觉风格与表演分别判断：画材、渲染和画质不决定人物的动作速度、幅度或情绪强度。新抬头只保留视觉与技术要求，不全局预设统一的动作速度、幅度、表情或生理细节；具体表演由原文情境、观看重点和可见程度决定，原动作和声源约束仍须保留。

以下面部、身体和发声方法按主体实际形态适用。动物、机械、非人形或其他特殊主体只使用已确立的感知、表达和运动结构；不得为满足词库而补造眉眼、手足、呼吸或人类口型。AU及人类生理示例仅适用于具备对应结构的主体。

焦点主体承担当前叙事或情绪看点、且需要由画面传达的动作过程、表情状态与变化须落实到成稿，不能只剩位置、朝向或动作终态；可省略的机械中段仍按摄影规则压缩。空间、景深和光照说明服务这些看点；说明写得详尽不等于表演成立。无转折时允许保持原情绪，必要可见表现须能由当前画面读取。内心声、刻意隐藏表情或声画反差按原文及既定呈现保留，不强制将内在情绪外化，也不能用内心声或语气代替原本需要看见的情绪；不把某种表情设为所有作品的默认或禁用状态。

## 叙事节拍与观看负荷

估时同时考虑三件事：观众需要辨认哪些必要信息，原动作中哪些步骤存在先后或接触因果，以及哪些表演变化需要被读懂。按本镜的实际可见范围安排，信息分散、遮挡较多或变化尚未建立时，先简化呈现或重排节拍，再决定是否增加时长；不以人物数量、提示词字数或情绪类别套固定秒数。

同一动作、画面关系与声音可以同时传递信息，不把识别、动作、反应机械拆成三镜或三个时长相加；确需先后才能理解的变化则留出相应过程与落点。短镜不等于只要动作能做完就足够，长镜也不等于自动更自然；无新动作但承担必要信息或原有保持的镜头仍可成立。

时长从必要节拍推算，仍遵守既有单元范围和1～6秒整数镜头轴；超出时先按自然切点重排，不能为满足预定镜数而删除观看重点，也不能补反应、停顿或运镜填满上限。具体省略判定沿用[动作节奏与压缩](cinematic-rules.md#动作节奏与压缩)。

## 可见程度与表情强度

下表适用于具有可辨面部表情的主体，只决定描述粒度，不决定动作数量或镜头类型。其他主体按其已确立表达结构和可见程度确定细节，未具备面部结构时无需补写面部描写。

| 等级 | 适用画面 | 写法 |
|---|---|---|
| 基础 | 中景/全景中确实可辨的面部 | 按画面中的实际大小、清晰度及遮挡判断，不因“全景”标签一律禁写；只写可读且有关的表情或视线，看不清肌肉细节时不写 |
| 标准 | 面部可读的近景、中近景、过肩正面一方 | 把原情绪落实到必要的眉眼、嘴部张力、视线或头颈；不要求全部部位同时变化 |
| 重点 | 面部为观看重点，或原文已有重要情绪转折 | 描述起始、原文触发点和变化后的落点；需要时写中间变化，强度不能超出原文 |
| 免除面部描写 | 远景、纯背影、道具镜、面部被遮挡或不足以辨认 | 免除不可见的面部细节，仍保留原叙事作用；用当前可见的既有姿态、动作、朝向、接触或物件关系承载，不为了填面部字段换镜头 |

强度使用“轻微可辨、清晰但克制、明显、强烈”等中文相对词，依据原文状态与本镜可辨程度选择。视觉风格只影响可见表达方式，不自动改变原文情绪强度。一个强度保持多镜可以成立；原文没有升级就不升级。表情保持不意味着必须增加眨眼、吞咽或呼吸声。

原有情绪、反差或接话转折中需要由画面传达的信息，不能因遮挡而遗漏；原文或既定呈现有意保留的遮蔽、内在情绪及信息延迟不强制外化。先核对实际露出的部位、景别、清晰范围与动作幅度，选择确能读取且不增添新含义的表达；局部露出不自动等于细微表情可读。若当前取景无法承载必要信息，可在既有事件内调整机位、取景或切点；不可见的挑眉等细节、单写“情绪可辨”或增加语气强度均不能替代可见实现，也不得擅自揭开既定遮挡或新增声响。

FACS/AU仅可作为作者熟悉且核实过含义的后台辅助，不要求模型依靠代码执行。成稿使用中文可见动作；不把某个AU、瞳孔大小、左右不对称或眨眼频率当作情绪、真假话或人格的证明。不采用通用的生理速度、角度、频率阈值。

## 表演词库与使用条件

词库仅提供条件适用的表达候选，以下解剖部位须由主体实际结构支持。具体动词不得赋予原文没有的含义；同镜选择能传达当前信息的必要部位，其他部位允许保持。

| 通道 | 可选可见描述 | 使用边界 |
|---|---|---|
| 眉部 | 眉心轻收、内眉略抬、眉间张力松开 | 对应原文已有状态；不由皱眉反推怀疑或敌意 |
| 眼睑 | 眼睑轻收、睁开幅度恢复、自然眨眼 | 面部可辨且有必要；不强制次数、停止眨眼或瞳孔变化 |
| 嘴部 | 嘴角张力收住、笑意渐淡、非发声间隙轻抿双唇 | 笑意变化须有原文依据；说话期间不同时要求紧闭双唇、咬紧牙关与清晰大幅口型 |
| 视线 | 看向既有人物/物件、沿原动作跟随、维持已有视线 | 写明实际对象；转移若意味着新发现、回避或怀疑，须有原文依据 |
| 头颈 | 维持朝向、随已有视线小幅转头、原动作中的颈部张力变化 | 不为丰富而强制低头/仰头；必要角度可近似说明，不改变已确立的主体态度 |
| 肩背 | 随原动作绷紧或放松、维持原有前倾/后靠 | 状态变化不得新增崩溃、退让或投降 |
| 手与接触 | 扶住既有接触点、完成原有递放、沿既有持握调整 | 不新增握拳、抚摸、取物、丢物等有叙事含义的动作 |
| 重心 | 支撑脚承接转体、重心随已有起身/行走转移、维持站姿 | 不新增失衡、退步或倒地；关键持物手与支撑关系须连续 |
| 呼吸 | 原有呼吸起伏、随原动作恢复呼吸节奏 | 中性起伏可按需；屏息、喘息、哽咽须符合原文，不能自动变成可闻音效 |

同镜多个通道可以服务同一个叙事信息，不必拆镜；同期完成的局部表现不重复累计时长。表达通道之间出现差异时须有原文或持续状态依据，不为了制造反差而安排相互矛盾的动作。

其他可见在场主体若与当前事件有关，先判断其是否实际听见或看见刺激，以及其反应是否影响本拍理解，再按上文具体化边界安排可感知的反应、持续活动或有意静止。优先在关键信息变化处选择相关人物回应，不以“非焦点”或“没有单独反应句”为由一律静止，也不把每个背景人物每镜动一次当作要求。优先呈现原文明写的反应与已确立持续活动；可由已成立的情境、刺激、关系与身体条件落实聆听、关注转移或克制反应，不新增判断、决定、移动目的或情绪升级。有依据的有意静止也可成立，应让其等待、约束或持续关注等现有作用通过实际可见状态读出；无事件关联或新行为依据时可保留已有中性状态，不为解释静止编造心理。

反应可错时、克制或持续到后镜，各主体按实际感知、位置、约束和行为机制呈现差异，不必逐人逐镜补动作、表情或反应条目，不要求全员动或统一同步。其余主体的持续行为不抢焦点、不重复焦点动作或他人台词；听者不代说、不跟随他人的台词做口型。真实画外或遮挡不要求画面呈现不可见细节，纯背影不写眉眼，模糊后景不写细微面部变化；只写当前画面能感知且与事件有关的内容。

## 身份与声音前检

## 场次冻结与集中修订

作者完成上述前检后，以完整自然场次或必要连续段保存不可变快照，由一个独立场次主审实读首版每镜。交接边界按真实连续性和材料规模确定；较大场次可在已有叙事边界分段，不按固定少量单元反复交接。交接含同版本渲染预览、该场单元及真实前后连接、对应原文、声音和资产依据；共用材料以可核验的冻结引用提供，无需反复展开无关全剧材料。一个写者负责连续稿，跨场单元不拆给多个写者；主代理验收交接、裁决冲突，并核对问题关闭及证据绑定，不再充当第三个逐镜审阅者。

审阅者只输出具体判断和问题，不修改正在写的草稿。每项问题包含快照摘要、镜头/字段、原值摘要、原文依据、根因、建议和关闭条件。同根因可以合并，保留所有受影响镜头；同字段修法冲突先由主代理裁决。先收齐冻结范围的反馈，交给唯一写者集中修订。真正阻塞身份、来源或后续连续性的错误立即报告，不等整场结束。

修订须按冻结target及已有稳定ID定位对象，再以字段路径、原值和对应摘要核对当前版本；不匹配时保留冲突，不能覆盖新稿或只刷新摘要。需要修改字段内片段时，先核实该片段的精确范围及语义归属；禁止对请求、渲染文本或原台词执行无边界的简称子串替换。同形词、复合词及普通提及不能因命中资产别称而改成视觉引用。修改动作/空间时按下述统一冻结前检查核对真实关联字段；未受影响的光照、摄影和持续状态可保留，不能机械重写全部字段。问题只有在实际修后复核满足关闭条件时才能关闭。集中一次修订是目标，残留矛盾或新问题仍须处理，不得仅因已完成预定轮次而接受仍有阻塞问题的结果。

按场冻结是证据和写入边界。后续草稿引用明确的前序版本；前序变化时相应后续依赖失效。待审期间可继续具有独立来源及进入状态依据的后续工作，写作与审阅可并行；依赖未决状态的内容须待相关问题解决。独立性依据原文及实际依赖判断，不能为并行制作新增重置或改变剧情。

## 复用已有逐镜判断

`scene_review.py`组合已有真实判断，不能产生语义通过。首次每镜均须实读；后续只复制与旧冻结快照、相关依赖精确一致且有具体依据的passed判断。旧报告必须与旧快照绑定，缺镜、重复、乱序、未知依赖或输入变化不能自动接收。

## 运镜词库

每镜明确选择固定或运动；采用运动时优先一个清楚的主运动，按方向、起始观看范围、速度、落点与必要稳定时机写入camera。缺少选择时返回待补，不默认固定、轻推或其他方式。微动也须有观看目的，不因幅度较小就自动适用；词库顺序不表示选择优先级，不据此循环分配。

| 方式 | 用法与可读落点 |
|---|---|
| 固定 | 明确稳定观察的对象与切出依据，使原动作、关系或有意义保持可读；不因镜头较短自动采用 |
| 小幅横移 | 沿既有关系轻微改变观察位置，停在能读清原动作的构图；空间不足时不用 |
| 微幅推进 | 缓慢缩小到既有观看重点，保持可读，不默认推向主体面部 |
| 轻微升降 | 从已知接触点过渡到相关主体，或调整遮挡；说明终点，避免无目的漂浮 |
| 小幅跟随 | 随原有位移调整相机位置，或转向主体实际观察的对象；明确起止范围，不给静止主体新增位移 |
| 慢推/慢拉 | 逐步突出既有信息或展开原有空间；不为了运动拉长台词 |
| 快推/突拉 | 需要在较短时间内突出已有信息或展开已有关系时评估；起点和落点均须可读，不因题材自动提高速度 |
| 横移/跟拍/升降 | 原位移、群像或空间揭示需要时使用；交代方向和结束构图 |
| 移焦 | 明确从哪个已有对象到哪个对象，时机绑定原注意力变化，保持景深描述一致；属于焦点变化，单独使用不计为实际相机运动 |

运动幅度只在距离、空间和镜头时间确实可判断时使用近似数值，不要求统一单位或阈值。1～3秒可连续采用有效的固定或运动，也可使用有可读落点的非微幅运动；4～6秒必须实际运镜。按观看目的及合法镜长复核，不设比例或最低移动量。
