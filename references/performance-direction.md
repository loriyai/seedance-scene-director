# 表演与台词导演

分镜起草和指定修改时随摄影规则读取。本文件负责把已确定的动作、情绪和台词写成可执行表现；机位选择查[镜头方案与词库](shot-options.md)，结构与校验查[后台接口](runtime.md)。不用于改写剧本、设计人物外观或改变资产身份。

## 约束顺序与落点

原文事实、动作次数/结果、情绪和声源类型先确定；再遵守已有时长、自然分句、资产及状态连续性规则；最后选择本文件的表现方法。方法和词库不能授权新事件，不能改写固定抬头文字、reference-v3结构或semantic-v2对白保真。原文要求持续平静或静止时允许保持，不为了表情弧线制造起伏。固定抬头中的眨眼、微表情、呼吸、衣物随风等通用描述，按本镜可见性及既有状态适用，不作为每镜动作配额或新增天气的原文依据；具体原动作和声源约束仍须保留。

不设置AU数量、微动作数量、三类表演齐全、每镜变化、固定空白时长或反应链完整四段等配额。先明确本镜要让观众读出什么，再写当前画面能看见的必要细节。自然微反应可具体化，但不得暗示未经确立的动机、态度、伤势、疾病或新增行动；汗、泪、受伤、武器脱手和环境变化继续要求原文依据。

| 工作步骤 | 复核与写入位置 |
|---|---|
| 核对原文 | 按来源顺序核对动作、台词、已有情绪与结果；需要表演转折时找到实际触发语句/动作。关键依据并入本镜purpose，不把原文未写当作可以自由补写 |
| 选择可见表演 | 按脸部可辨程度选择描述密度，决定保持或变化；同一反应的脸、视线、身体共同服从一个原文状态 |
| 规划声音和时间 | 按声源选择必要韵律，再用既有audio.speed、units和pause估时或沿用录音实测；同期表演不重复加时，顺序动作才累加 |
| 选择镜头 | 依据观看重点选景别、机位与切点；面部不可见时用原有动作/关系承担信息，不强行增加面部镜 |
| 写成稿 | 动作、可见表情和必要口型写shots.text；有必要的声音表现写dialogue_parts.delivery；摄影写camera/composition/depth_of_field/lighting；原台词仅写dialogue_parts.text |
| 单元检查与续接 | 检查触发顺序、事件次数、语气/口型、时长和语义分句；end_state只记录原事件产生的状态，下一单元承接，不能每块重新反应 |

分镜规划和复核依据留后台，成稿不输出L1/L2/L3标签、AU列表、强度评分、反应链编号、来源说明或自检结论。既有字段已经承载这些内容，不增加需要用户填写的表演表或确认步骤。

## 可见程度与表情强度

分级只决定描述粒度，不决定必须有几项动作或使用哪种镜头。

| 等级 | 适用画面 | 写法 |
|---|---|---|
| 基础 | 中景/全景中确实可辨的面部 | 简短写与本镜看点有关的表情或视线状态；看不清肌肉细节时不写 |
| 标准 | 面部可读的近景、中近景、过肩正面一方 | 把原情绪落实到必要的眉眼、嘴部张力、视线或头颈；不要堆满所有部位 |
| 重点 | 面部为观看重点，或原文已有重要情绪转折 | 描述起始、原文触发点和变化后的落点；需要时写中间变化，强度不能超出原文 |
| 免除面部描写 | 远景、纯背影、道具镜、面部被遮挡或不足以辨认 | 用已存在的姿态、动作、物件关系表达本镜信息；不为了填面部字段换镜头 |

强度使用“轻微可辨、清晰但克制、明显、强烈”等中文相对词，按原文和当前风格选择。一个强度保持多镜可以成立；原文没有升级就不升级。表情保持不等于画面冻结，也不意味着必须增加眨眼、吞咽或呼吸声。

FACS/AU仅可作为作者熟悉且核实过含义的后台辅助，不要求模型依靠代码执行。成稿使用中文可见动作；不把某个AU、瞳孔大小、左右不对称或眨眼频率当作情绪、真假话或人格的证明。不采用通用的生理速度、角度、频率阈值。

## 表演词库与使用条件

词库是选择材料，不是每镜清单；具体动词不能自行赋予原文没有的含义。同一镜选择能表达本镜信息的部位，其他部位可以保持。

| 通道 | 可选可见描述 | 使用边界 |
|---|---|---|
| 眉部 | 眉心轻收、内眉略抬、眉间张力松开 | 对应原文已有状态；不由皱眉反推怀疑或敌意 |
| 眼睑 | 眼睑轻收、睁开幅度恢复、自然眨眼 | 面部可辨且有必要；不强制次数、停止眨眼或瞳孔变化 |
| 嘴部 | 嘴角张力收住、笑意渐淡、非发声间隙轻抿双唇 | 笑意变化须有原文依据；说话期间不同时要求紧闭双唇、咬死牙关与清晰大幅口型 |
| 视线 | 看向既有人物/物件、沿原动作跟随、维持已有视线 | 写明实际对象；转移若意味着新发现、回避或怀疑，须有原文依据 |
| 头颈 | 维持朝向、随已有视线小幅转头、原动作中的颈部张力变化 | 不为丰富而强制低头/仰头；必要角度可近似说明，不暗改人物态度 |
| 肩背 | 随原动作绷紧或放松、维持原有前倾/后靠 | 状态变化不得新增崩溃、退让或投降 |
| 手与接触 | 扶住既有接触点、完成原有递放、沿既有持握调整 | 不新增握拳、抚摸、取物、丢物等有叙事含义的动作 |
| 重心 | 支撑脚承接转体、重心随已有起身/行走转移、维持站姿 | 不新增失衡、退步或倒地；关键持物手与支撑关系须连续 |
| 呼吸 | 原有呼吸起伏、随原动作恢复呼吸节奏 | 中性起伏可按需；屏息、喘息、哽咽须符合原文，不能自动变成可闻音效 |

同镜多个通道可以服务同一个叙事信息，不必拆镜；不把同时发生的眉眼、手部与呼吸细节相加成额外时长。也不要求这些通道必须互相“反驳”。

听者先呈现原文明写的反应；没有反应时可维持已有姿态与视线，确有必要才写中性在场细节；已有疲惫、警惕等状态可延续，不升级。纯背影不写眉眼，模糊后景不写细微面部变化，群像不逐人铺满同一套微动作。听者不代说、不跟随他人的台词做口型。

## 表情弧线与反应过程

仅在原文已有情绪变化时使用“起始状态→原文触发→可见变化→落点”。触发优先绑定原有语义/动作节拍，如“听到对方说出关键信息后”；不把完整台词再次抄到动作正文中。无需为每个长于某秒数的镜头制造两段或三段表情。

重大信息或受击等原文事件，可用“刺激→身体响应→外显结果”检查因果；只选原文支持、画面可见且叙事必要的环节。省略不可见环节可以成立，不补写心率、血流、瞳孔变化等来填四段。受击不自动推出流血、脱手或倒地；原文停在即将命中时不能提前演受击。

原文有沉默、愣住或停顿时，可保留维持生命感的细微姿态；不强制0.8～1.2秒空白，不强制空白后吞咽/深吸气，也不补风雾等环境动态。原文已有的动作戏顿帧、冲击帧和时间静止仍按摄影规则使用，不将其混同于普通对话僵住。

表演过程应在已排镜头内可读。需要写准确内部分点时留在后台；成稿优先用触发与先后关系，保留1～5秒整数镜头轴。不因细节文字更长而延长镜头，也不把确实先后发生、无法同期完成的动作硬塞到一个短镜。

## 动作执行检查

对关键接触、持物交接、复杂转体或易歧义动作，检查：执行部位、接触点、方向/路径、重心/支撑、结束状态。只写使原动作可理解的必要项，不逐个动作强制写满五项，不增加动作次数、临时物件或攻击招式。

未知但不影响剧情的持物手可确定并保持；决定结果的左右/接触位置不能猜测。机械中段仍可按摄影规则压缩，关键因果与结果不能省。结束状态须与下一镜或下一单元承接，已完成的开门、交接等不再次执行。

## 台词韵律词库

先保留原台词、说话人、情绪提示与发声类型，再考虑以下维度。每条台词都作语气判断，但普通清晰陈述可省略额外标注；原文有明确低声、急促、强忍等要求或本镜声音差异承担信息时，写必要取值，不强制四项齐全。声音词库不授权新增隐藏动机。

| 维度 | 可选词句 | 数据与约束 |
|---|---|---|
| 音量 | 轻声、压低音量、自然音量、提高音量 | delivery.volume；轻声不自动等于悲伤，提高音量不自动等于愤怒 |
| 语速 | 自然语速、较快语速、放缓语速 | 唯一来源为audio.speed的常速/快节奏/情绪慢速；不在delivery另设语速或速率 |
| 尾音 | 平稳收住、短促收住、轻微上扬、逐渐下沉 | delivery.ending；须符合语义与原有态度，不凭问号设计嘲讽 |
| 发声质感 | 清晰自然、轻微气声、绷紧声线、原有沙哑声线 | delivery.texture；沙哑、哭腔等须有依据，不借此改变角色身份/音色资产或制造伤病 |
| 咬字 | 清楚连贯、字头清晰、收音轻、原文指定词句重读 | delivery.articulation；描述听觉，不填嘴部开合角度；不新增嗤笑、呻吟、吸气等有声事件 |
| 停顿 | 原文停顿、完整语义气口、原有打断 | 只登记audio.pause及dialogue_parts时码；不把切镜、表情标注、breath_basis自动当成额外停顿 |
| 可见口型 | 随本镜实际发声自然开合、按原发音收口 | 只在实际现场声源且嘴部可见、有必要时写shots.text；OS/画外音/旁白不要求画内人物张嘴 |

delivery为可选非空对象，可用volume、ending、texture、articulation中的一项或多项；值是单行中文声音描述。不要放台词、资产引用、时码、语速或停顿数值。程序在声源标签后、原台词引号前渲染这些值，并从audio.speed补语速。详见[delivery接口](runtime.md#台词表现字段delivery)。

改变语速会影响文本估时，必须重新估算并检查分句时码；改变尾音若涉及实际延长也要计入，不得用“韵律不占时长”绕过校验。录音已确定时描述跟随录音，不用文字标签强改实际测量。普通同期面部/身体表现不重复占用声音时长。

同一句跨镜时继承原语气，除非原文在该分句确有转折；不要切一次镜就重新起调、换音色或重复吸气。若一句内部有明显速度变化，audio.speed按整句实际可读速度归档，时码按实际分句安排；不按字符比例切分，不发明片段级另一套速度数值。旧交付无delivery时保持原样，不自动补标。

原文明示强装轻松、言不由衷时，才可用尾音或发声张力表达已经确立的反差，并将依据写入purpose。不把普通陈述设计成说谎；方言仅按原文/已确认需求，保留原词，不套地域口型刻板模板。

## 单元复核

1. 表情、反应和声音强度都有原文/持续状态依据，或属于不携带新含义的必要具体化；没有为丰富度新增心理、动作或结果。
2. 描写确实能从本镜看见；触发发生在反应之前，嘴部动作与实际声源相容，听者和画外声源没有代说。
3. 保持与变化均有观看目的，没有机械补三段表情、完整级联或固定空白；动作只完成原有次数。
4. delivery在引号外，原台词逐字拼接一致；语速取自audio.speed，停顿只计算一次，语气改变后已经重新核对时间。
5. 已采用的动作/声音状态与前后镜及单元衔接；未选择的技巧不输出“无AU”“无级联”等占位。

这些语义判断由生成者完成。字段检查、AU编号或数值精细程度不能证明表演自然，更不能证明实际视频已准确执行。
