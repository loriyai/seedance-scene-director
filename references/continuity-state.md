# 最小连续性记录

这份后台接口适用于所有题材，只记录影响剧情和承接的重要实体。它不输出到提示词，不改变固定抬头、节点菜单、镜时长规则或旧receipt。程序只检查声明是否完整、自洽及引用是否位于选定原文；不能证明构图正确、表演自然，也不能判断引文是否确实支持所声明事件。

## 生成顺序与记录边界

先区分同时成立的状态与改变状态的事件，再规划节拍、估时、摄影。原文描述顺序不自动等于事件发生顺序。分别判断实体在场、摄影可见性和观看焦点；换焦点、虚化、画外、遮挡都不构成离场。先固定必要的实体关系，再选择机位及画面左右。

实体ID在连续单元间稳定；同一人物的不同图片形象共用实体ID，`asset_id`记录当前形象。台账中已有的群像可作为一个资产实体；共用图片的不同实物可登记不同实体ID。不要用改名绕过承接检查。资产映射及群体拆合是否符合原文仍须人工确认。只保留必要事实，不为填表发明坐标、动作或心理。

## 单元字段

新生成和指定替换的单元新增`continuity`：

```json
{
  "version": 1,
  "boundary": {"kind": "continuous"},
  "entities": {
    "person": {"asset_ids": ["CHAR0001"]}
  },
  "initial": {
    "person": {"present": true, "asset_id": "CHAR0001", "facts": {"位置": "门内", "持有": "空手"}}
  },
  "final": {
    "person": {"present": true, "asset_id": "CHAR0001", "facts": {"位置": "门内", "持有": "空手"}}
  }
}
```

- `boundary.kind=continuous`继承来源相邻单元末态，包括换机位后仍成立的实体关系。实际时间、地点或叙事层跳转可用`reset`，必须同时填写非空`reason`与`evidence`；不能把常规切镜当重置。
- `entities`以稳定实体ID为键；已建资产仅填写`asset_ids`（CHAR/PROP ID数组，可包括同实体的不同形象，但不得混合人物和道具）。只在画外的已登记实体可以不列入本单元`character_ids`/`prop_ids`。
- 原文支持且按现有资产规则不需建图片资产的临时物件、空间参照或环境状态，填写`{"asset_ids":[],"label":"名称","evidence":[{"record":"L000003","quote":"原文逐字片段"}]}`；`asset_id`为`null`，不进入资产subjects，不由此新增资产节点。实体存在依据可引用本单元末尾之前已经到达的原文，允许承接早先建立的实体，不要求每单元重复出现名称，禁止借用后续原文。仅作关系描述的空间参照可写在facts值中，不强制独立登记实体。不得把已登记人物/道具改成空asset_ids绕过引用，也不得通过后台元数据新增未经原有身份流程处理的人物或群像；完整名称的直接冒用会拒绝，别名或身份关系仍须人工核对。
- `initial`和`final`恰好包含全部登记实体。每项为`present`布尔值、当前`asset_id`和`facts`对象。`present`表示实体在当前叙事场面内，画外在场为true，远处画外声源可以为false。`facts`使用必要且稳定的关系或状态键及非空字符串值；仅无相关关系/状态需要追踪时可为空对象，不用空对象绕开必要检查。不把画面左/右作为真实场面位置；相同事实沿用同一键和值，不改换同义词制造或绕过变化。
- `final`必须等于从`initial`逐镜重放变化得到的结果。不变事实自动继承，不逐镜复制完整快照。

每镜新增`continuity`：

```json
{
  "changes": [],
  "visibility": {
    "person": {"mode": "visible", "basis": "人物上身在门内构图中可见"}
  }
}
```

- `visibility`每镜恰好覆盖全部登记实体。`mode`为`visible`（包括部分可见）、`offscreen`（在场但取景外）、`occluded`（完全被遮挡）、`absent`（本镜全程不在当前场面）；每项`basis`具体解释可见区域或取景、遮挡、离场依据。虚化但能确认人物存在仍为`visible`。
- 可见注册资产须列入本镜`subjects`；`subjects`每项须有对应可见实体，`focus`不能指向完全遮挡或画外实体。仅声音参与者写`audio`。允许同一镜内进入、离开或变化形象，不要求焦点在镜尾仍在场。
- `changes`按发生顺序登记源于原文的变化：`{"entity":"person","set":{"facts":{"持有":"信件"}},"evidence":[{"record":"L000004","quote":"接过信件"}]}`。`set`只更新`present`、`asset_id`、`facts`；facts逐键合并，值为`null`删除已有事实。不变内容不登记为变化。
- 每次变化及局部实体证据使用`[{"record":"标准正文行ID","quote":"逐字引文"}]`。事件变化及重置的引文必须位于本单元实际选定的行内片段，不可借用同一行尚未选入的后文；局部实体的存在依据另允许已到达的前文。引文只证明来源存在，不证明语义解释成立。
- 边界重置也可以引用本单元场景标题：`{"kind":"reset","reason":"原文转到城门","evidence":[{"scene":"SC0002","quote":"场景2-日-外-城门"}]}`。所有reset返回人工复核提醒，确认原文确实支持重置。初始选定范围没有已知前序时可直接使用continuous，不杜撰前史。

## 检查与兼容

`continuity.validate_unit(state, unit, required=False)`：有记录时校验并返回`version/warnings/initial/final/entities/boundary`；无记录且非required返回`None`。`validate_chain(state, prospective_units, touched_indices)`只检查涉及新提交或替换单元的来源相邻边界，返回边界提醒；替换同时比较前后邻居。回退范围的追加也按来源位置查找已有后继，不依赖数组存储顺序。有有效前序链接时使用该链接，否则要求唯一来源相邻候选；多个候选只提示人工确认，不任意选择版本。

连续边界相同实体的在场状态、活动形象及前序已登记facts须保持一致，不能无事件更改或删除已有事实；新加入此前未追踪的事实键只触发原文与既有状态核对提醒，不要求补造动作。前序仍在场实体不能漏掉，前序已明确不在场的实体不能无事件直接变为在场。前序未追踪而本单元首次追踪的在场实体触发原文与既有场面核对提醒，不自动判定新登场，不补造进入动作，也不要求提前登记所有未来实体。已离场实体可不再追踪。真实跳转使用有依据的reset。单元边界上的动作写入一个对应镜头，不用私自改变下一单元initial绕过事件记录。相同实体可在后续单元补充形象映射，不要求最初登记全部未来形象；活动形象变化仍须有事件证据。

新请求必须有记录，旧单元读取、渲染和幂等重试不强制迁移。旧相邻单元没有记录时只提示人工核对，不补写历史或重新校验未选内容。检查不追溯非相邻来源空隙。通过程序检查后仍须核对原文支持、实体身份、状态是否落实为可见的构图与动作、表演负荷、环境和声音连续性；用户提供成片时另做验收，不自动生成视频测试。
