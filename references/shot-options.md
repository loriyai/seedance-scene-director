# 镜头方案与词库

在阶段4选择或修改机位时读取，配合[摄影规则](cinematic-rules.md)和[表演导演](performance-direction.md)。以下都是有目的的可选方案，不设镜头比例、相邻换景别、焦段跨度、机位高度种数或移动次数配额。

## 选择顺序

先依据场面状态与叙事节拍确定观看重点，保留实体间已有的位置、朝向、接触与持有关系；再确认资产/参考图实际覆盖、空间和轴线，最后组合机位方位、高度、景别与主运动，并推导当前画面的左右、前后景及遮挡。画面位置随机位变化，不能反过来改变实体关系。angle保留后台已有粗分类，精确方位和高度写camera，不增加新的angle枚举；景别仍使用接口已有值。组合不能制造新的权力关系或原文没有的反应。

| 维度 | 备选词库 | 使用方法 |
|---|---|---|
| 方位 | 正面、斜侧、侧面、背侧、背面、过肩、主观观察 | 服务实际视线/动线；纯背面不要求面部表演，过肩背对者不写眉眼 |
| 高度 | 平视、轻微俯视/仰视、较高俯视、低位、地面附近、顶拍、高位越肩 | 选择能看清动作和关系的高度；不把俯仰角机械解释成压迫/屈服 |
| 画面关系 | 双人同框、前后景关系、已有前景遮挡、动作局部、空间全貌 | 区分相机、人物和物件位置；不因换镜凭空增加门框、栏杆、镜面 |

高度与方位独立考虑：例如同一侧面观察可以平视，也可低位看清脚步；只有原动作/空间支持时采用。角度或机位高度需要消歧时可给近似值，不要求每镜数字化。

## 按叙事看点查候选

只查当前节拍需要的行；候选不是固定套餐，同一情境允许不同有效拍法。本文件所有固定机位候选与示例仅适用于1～3秒；4～6秒必须选择服务观看重点的真实相机位移或转向，仅移焦或主体运动不算，运动后可短暂稳定。

| 本镜要读懂什么 | 可考虑的拍法 | 取舍依据 |
|---|---|---|
| 谁在对谁、关系与距离 | 双人中景、过肩、空间全景 | 关系尚不清楚时保留双方；已建立后可收窄，不要求每段重做定场 |
| 原有交接、接触或阻挡 | 侧向/斜侧中景、手部或道具局部 | 路径与参与者是新信息时保全；只需指认细节且关系已清楚时才取局部 |
| 原有信息落到听者 | 听者近景、带说者前景的过肩、同框中的已有动作中断 | 反应必须来自原文或持续状态；按反应价值选焦点，不按谁开口轮换脸 |
| 原有威胁、反转或关键揭示 | 快推到动作/物件、拉开显露空间、有意义的固定 | 速度反差突出哪个信息？若保持更能读清，也可固定；没有触发不造刺激 |
| 原有距离或强弱关系变化 | 同框、前后景关系、已有高度差、取景比例变化 | 先有剧本关系与真实调度，再用摄影表达；不借机位新增逼近、退让或服从 |
| 原有结束、孤立或释然 | 固定保持、拉远展开、中景中的原有收势 | 需读空间余韵才展开，需读具体状态则保持；不强制加留白或收尾动作 |

关键转折、复杂交互或疑似重复摄影需要取舍时，比较两个可拍方案：各自保留了什么观看信息、会失去什么、当前空间与参考是否支持。普通镜头直接选择即可，不另写比较表或增加审阅轮次。选定原因仍压成既有 `purpose` 一句话，例如“交接关系尚未建立，用同框中景保留双方手部与递送路径”；不能用“更丰富、更高级”代替依据。若两案都需补造动作/物件，回到原看点重选。

## 参考图有限时的备选方案

本Skill标准人物板已有面部特写及正、侧、背三视图；先检查实际素材是否清晰、齐全，不能假定已生成或覆盖任意角度。资产参考说明身份与结构，不代替本镜剧情状态：空布景参考不表示场面无人，独立物件参考也不决定其当前持有者；必要实体关系仍须按原文状态落实到镜头。单一空间视图不自动保证换机位后的结构与遮挡正确。下列方法可能减少可见面部细节需求，不承诺消除身份、服装、身体或空间一致性风险。

该三视板只适用于个体角色；新版群像板是多个不同成员各一幅正面全身样本，不自动具备同成员的侧背参考。遮面造型只展示当前可见的头部与身体，不能从底稿知道五官就要求镜头穿透头套展示眉嘴。使用前核对当前造型、覆盖部位及实际图片，群像样本人数不限定剧情人数。

| 方案 | 适用看点 | 使用前核对 |
|---|---|---|
| 过肩/背侧 | 原有对话关系、对方动作 | 两人真实站位、轴线、肩背造型；背对者面部不可见 |
| 原有前景遮挡 | 原有窥视关系或空间层次 | 遮挡物已经存在，不为回避面部而新增遮挡行为 |
| 手部/道具/脚步局部 | 原文已有的交接、接触、位移 | 动作本身有信息、手脚及道具参考可信；不凑特写或新增物件 |
| 高位/顶拍/低位 | 原有空间关系、桌面动作、地面动作 | 空间结构与身体比例有支撑；不默认极端角度更安全 |
| 全景/远景 | 需要交代的原有空间与动线 | 环境信息有依据，脸部仍按实际可见程度处理，不增加空镜 |
| 已有反射面 | 原剧情或明确构图需要的反射关系 | 反射面确实存在且位置、朝向合理；反射可能增加一致性负担，不作为默认补救 |

大幅环绕、显著侧脸或面部大特写需要核对实际图像可辨细节和角度，不用某个焦段或角度阈值保证生成质量。若某角度缺少必要支撑，优先选择同一叙事信息的已有可行拍法；只有核心信息无法可靠表达时才提出具体补图需求。没有实际图片时可继续规划并保留待补状态，不自动触发生图或阻断空节点工作流。

## 运镜词库

每镜优先一个清楚的主运动，按方向、起始观看范围、速度感、落点与稳定时机写入camera。微动也计为运动，不自动再叠加另一种运动。不从词库随机轮换。

| 方式 | 用法与可读落点 |
|---|---|
| 固定 | 明确机位固定，让原动作、关系或有意义保持承担变化；不必套四类固定理由 |
| 小幅横移 | 沿既有关系轻微改变观察位置，停在能读清原动作的构图；空间不足时不用 |
| 微幅推进 | 缓慢缩小到既有观看重点，保持可读，不默认推到正脸 |
| 轻微升降 | 从已知接触点过渡到相关主体，或调整遮挡；说明终点，避免无目的漂浮 |
| 小幅跟随 | 随原有视线/位移作有限调整，不给静止人物编造移动 |
| 慢推/慢拉 | 逐步突出既有信息或展开原有空间；不为了运动拉长台词 |
| 快推/突拉 | 原文已有的威胁、反转或爆发需要速度反差时使用；落点可为动作或物件 |
| 横移/跟拍/升降 | 原位移、群像或空间揭示需要时使用；交代方向和结束构图 |
| 移焦 | 明确从哪个已有对象到哪个对象，时机绑定原注意力变化；保持景深描述一致 |

小幅不等于必须写厘米/秒；只有运动距离、空间和镜头时间确实可判断时才用近似数值。1～3秒固定与有目的的微动都可以连续出现；4～6秒必须实际运镜。按观看目的及合法镜长复核，不另设比例或最低移动量。

### 需要具体落点时查短例

以下均为**虚构、未成片验证**的既有字段局部示意，不是完整提示词或生成效果保证。前提表示示例原文/已确认制作空间，不能移植成项目事实；实际镜长仍按内容落在1～6秒整数轴。示例 `@{CHAR0001}`、`@{CHAR0002}`、`@{CHAR0003}`、`@{PROP0001}` 仅表示假定已登记的资产，使用时换成项目真实稳定ID，由现有渲染器输出 `@台账完整name `；未登记物件按现有资产规则处理，不照例新建引用。

| 示例前提 | `camera` 局部示意 |
|---|---|
| 原文人物按住桌上的信，保持不打开 | 桌侧平视固定，保持 `@{CHAR0001}` 的手与 `@{PROP0001}` 同在取景内 |
| 原文此时发现柱后的另一人；柱为既有布景结构 | 从柱边向右小幅横移，露出柱后 `@{CHAR0002}` 的上身后停住；途中遮挡须由实际空间确认 |
| 原文人物走到已有门旁停下 | 从 `@{CHAR0001}` 侧后方同向跟随至门旁，随其停步稳定，终幅保留身体与门的位置关系 |
| 原文另一人突然亮出关键信件 | 从双人中景迅速推近 `@{PROP0001}` ，落在持信手与信件局部后稳定 |
| 原文视线由信转向对方，两者均在取景内 | 机位固定，焦点由近前景 `@{PROP0001}` 转到中景 `@{CHAR0002}` ；`depth_of_field` 同步写明终点清晰对象 |

相邻镜也按原事件选择静动关系：**静切动**可用于原文“站着听完后走向门”——前镜固定，后镜在实际起步时跟随；**动切静**可用于原文“走到门前停下，听门内动静”——跟随至停步，再固定承载已有的听声状态。切换方式写 `transition`，具体动作/视线接续按需写 `connector/text`，理由写 `purpose`；若一个镜头已读清全部信息，就在该镜内稳定收住，不为凑组合加镜。

## 空间推导例：按当前难点查用

三例同样为**虚构、未成片验证**的字段示意，沿用上方引用口径。只示范“场面关系→相机→可见性→原字段”，没有覆盖完整输出；其他摄影字段仍按本镜实况填写。

- **正反打/过肩（虚构·未成片验证）**：假定原文两人隔桌对坐、互相注视；制作空间已确定甲在桌西、乙在桌东，桌南侧可架机。相机置甲后侧偏南、朝乙拍，甲肩背可作前景，甲正脸不可见。`camera` 写“从 `@{CHAR0001}` 后侧偏南越肩固定，朝向 `@{CHAR0002}` ”；`composition` 写“`@{CHAR0001}` 肩背在左前景边缘，`@{CHAR0002}` 上身为主焦点”；`depth_of_field` 写“`@{CHAR0002}` 面部清晰，前景 `@{CHAR0001}` 肩背略柔”。反打时相机换到乙后侧偏南，仍在轴线南侧，重新推导可见性与画面左右，不复制上一镜背景或给背对者写眉眼。
- **车内多人（虚构·未成片验证）**：假定原文车已停稳，甲在驾驶座、乙和丙分坐后排左右，乙看丙说话；当前车内参考支持前排中央向后的取景。相机从前排中央向后拍，两位后排人物可见，驾驶座在机位后方。`camera` 写“前排中央向后排平视固定”；`composition` 写“`@{CHAR0002}` 与 `@{CHAR0003}` 按原坐席同框”；`global` 写三人的起始坐席，单元 `continuity.initial/final` 的各实体 `facts` 保留坐席且 `present=true`。本镜 `shots[].continuity.visibility` 将甲记为 `mode=offscreen`，`basis` 说明驾驶座位于朝后取景的机位后方；乙丙记为 `visible` 并说明可见身体范围。`subjects` 包含乙丙，`focus` 按原看点选择。不能把甲删除、挪到后排，或凭后排一人近景推断另一人离场。
- **道具交接（虚构·未成片验证）**：假定原文两人隔桌相对，甲右手递出唯一一封信，乙左手接住后甲松手。相机在双方同侧斜向观察，取景保住双手与递送路径。`camera` 写“桌侧略俯固定，取双方手部及 `@{PROP0001}` 的近景”；`composition` 写明两只手在信两端的实际位置，`depth_of_field` 让双手接触处与信清晰。`text` 写接住后才松手，`shots[].continuity.changes` 由原事件把同一信件的持有状态从甲右手更新到乙左手；后镜承接乙已持信，不重做交接，也不让甲手中留第二封信。若局部镜无法交代尚未知的双方关系，改同框中景。

## 焦段与景深选择

焦段/光圈是可选辅助，不设每镜必填、不固定焦段对应景别，也不要求每块长短焦各一次。可用“较广视角保留空间、中等视角保持关系、较窄视角突出局部”等中文；需要具体数字时先考虑镜距、取景范围、成像规格与前后景距离，不把单个焦段或光圈值直接判为必然深/浅景深。

camera可写焦段与光圈，depth_of_field仍明确实际对焦对象及清晰范围。移焦起点/终点与该字段一致；同景别或同焦段的有效正反打允许保留。参数不能代替画面目的，不以更长焦、更浅景深自动代表更强情绪。

## 使用后复核

检查原文观看重点是否保留、相机是否架得下、实体关系与画面投影是否一致、轴线与遮挡是否可信、参考资产是否足以支撑、主运动及其可读落点是否能在本镜完成；检查同一表情或构图是否仅换标签。确有不同看点或有意义保持时，允许相同景别、焦段及光照继续使用；固定机位的延续须使各镜均为1～3秒，4～6秒仍须实际运镜。

purpose、visibility.basis及景深必须来自本镜实际决策，不由label/camera拼接“完整可读”或根据subjects倒推出取景外理由。生成脚本只组装作者已经决定的字段，缺失时留待补全，不自行制造审查依据。最终逐镜复核对照来源、进入状态和完整镜头；摄影相同不自动失败，填满字段不自动通过。
