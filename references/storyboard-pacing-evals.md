# 分镜节奏回归样例

本页用于修改分镜节奏规则后的行为验证。测试控制者持有原始场景和验收依据。写者和主审只接收各自测试所需的输入。日常分镜制作直接使用[创作规则](storyboard-rules.md#动作节奏与转场)和[审阅流程](storyboard-workflow.md#场次审阅)。

## 原始场景和验收依据

| 编号 | 题材 | 原始场景 | 验收依据 |
| --- | --- | --- | --- |
| D1 | 日常走位、短内心声 | 夜，夏侯玄听见窗外隐约的欢呼，关上侧窗，坐回近旁书案前。他内心想「系统。」案前虚拟屏幕展开。 | 保留欢呼、合窗、坐回原位、闭唇内心声和光屏接续。可在转身处省去到椅边的中段，两字内心声可以接在落座收势。曾有三镜 11 秒的处理，参考修订为两镜约 4 秒后接光屏。其他可执行拍法按实际因果和节奏验收。 |
| D2 | 日常动作中的信息等待 | 姑娘走到屋门前，手刚搭上门闩，听见里面有人压低声音咳了一下。她停住，等屋里再传出一声咳嗽，这才抽开门闩。 | 到门边的普通路程可省。保留手停在闩上、第一声与第二声的区别、听见第二声之后才抽闩。第二声前的留时承担叙事作用。 |
| H1 | 无对白交接 | 桌边的伙计拿起一只空杯，递给对面伸手的同伴。对方接牢后，伙计松手，转身去收桌上的托盘。 | 让接杯和松手在同一动作里可读，直接接转身。已完成的持杯姿态和空手回正无须各占一镜。 |
| H2 | 无对白承重 | 父亲背着睡着的孩子走到粥棚。妻子托住孩子的背和腿，把重量稳稳接到自己手里。父亲确认她托稳才松开原先扶孩子的手，腾手接过粥碗。 | 原支撑、重量转移、托稳后松手、接碗的因果清楚。可省排队或走位。构图须让关键接点可读。 |
| A1 | 快速动作 | 巷口，袭击者从近处侧面突然挥拳。拳打在守门人的前臂上，守门人以臂架住，立刻把门拉上。 | 及时见到接触、架住和拉门。可剪过无意义的蓄势及回正。三项有真实先后，拳和拉门各只发生一次。 |
| A2 | 受力结果驱动下一动作 | 木工一锤落在松动的门楔上。门楔受击斜弹，撞到地上滚向脚边，木工看清方向，抬脚让它滚过。 | 保留一锤的接触、弹出、触地后的滚向和抬脚躲让。可省无关准备。结果可以跨镜连续呈现。 |
| P1 | 工序讲解 | 师傅在桌边给学徒看同一张无字的榫卯图。他的指尖沿图上的接合线移动一遍，说「这两头要合紧。」学徒点头。 | 指尖和必要的观察可与原话同期。呈现一遍接合线，保留一次有依据的点头。已经看清的图和同一次反应无须重复呈现。 |
| P2 | 工序与可见因果 | 学徒第一次试织。师傅拨开经线，学徒从开口送梭，随后推筘压紧。布边比上一道多了一行。 | 保留分经形成开口、梭穿过、推筘后布边增长的顺序。各相位和状态变化须可辨。 |
| S1 | 线索与单次反应 | 夜里，年轻守卫从门缝看见地上有一道新鲜湿脚印。他吃了一惊，抬眼沿脚印看向走廊深处。 | 展示湿脚印、一次受刺激的反应、抬眼找到正确方向。可以换镜表现观察转移，避免同一惊讶重新起势。 |
| S2 | 悬疑等待与判断变化 | 夜，书房门上响了一下。主人以为是风，手仍在桌上。屋内静下来，他屏住呼吸，第二次敲门响得更近，他才起身看门。 | 第一次与第二次声响之间有可读的静默、屏息及判断变化。保留听见第二次后才起身。等待时长由事件实际作用决定。 |
| B1 | 昏厥与画外音 | 街口，新娘撞上轿框倒地。切黑。两名路人先后画外议论她的安危与退婚。亮起，她皱眉、睁眼。 | 有明示切黑依据，连续纯黑恰为3秒可通过时长检查。若两镜各黑2秒，即使分属不同单元，累计4秒也须退回；3秒接5秒同样退回。人物苏醒按原时机呈现。 |
| B2 | 黑中辨声与揭示 | 剧本指定保持纯黑听完两句共8秒的证词，最后一个字之后才揭晓听者身份。 | 持续黑8秒须退回。纯黑最多3秒，此后可呈现来源已成立、不会泄露听者身份的画面；保留完整证词与最终揭示点。 |
| B3 | 昏厥没有切黑指令 | 邮差摔倒，信封落地，同伴在画外呼唤他。 | 用落地的信封、邮差的手或其他已有可见关系承接声音。即使只有1秒，自行加入纯黑也须退回。 |

## 盲测与记录

1. **写者。** 每个样例在三个彼此独立的新会话中各跑一次。向写者提供原始场景、正常分镜请求及待验证版本的 Skill 规则。把验收依据、参考时码和旧稿留在控制端。保存首稿的镜头正文、切点和必要的发声窗口。对照实际稿件判断能否剪过、何时同期、关键相位是否可读。记录无依据等待、重复展示、错失同期、动作过载及必保内容丢失，按场景和具体镜号定位。
2. **主审。** 对同一来源准备一份可执行稿、一份故意拖长稿和一份故意剪掉关键相位的稿。保持时码与基础格式可读，避免用格式错误泄露错稿。将候选匿名混排，给主审原始场景、待审稿及同版审阅规则。验收依据和预期结论留在控制端。错稿须被退回且意见应准确定位主缺陷。合格稿因错误删除必要等待、接触或结果而被退回，记作误判。预设合格稿被退回时，先按原文核实主审指出的问题。确有缺陷时单列为样稿缺陷，修订后交新会话盲审。对同一来源的不同候选，分开交给相互隔离的主审会话。
3. **闭环。** 分开记首稿漏执行、已识别并修订、审阅漏放、合格稿误退及过度压缩。首稿有问题、主审识别且修订后保住必保内容时，写作问题与审阅拦截分别记账。统计同时注明实际覆盖的题材、样例、会话数量与未覆盖范围。
4. **验证线。** 测试中已知错稿零放行、最终稿必保内容零丢失。再提供至少一个未见场景，仅给原始内容，核对写者和主审能否迁移判断。时长、镜数与术语只作定位线索，结论取自实际动作、声画和接续。有限样例的结果用于判断本次改动表现。

测试在隔离目录进行。测试稿与测试审阅意见供核验使用，正式提交和画布操作由实际制作请求的授权决定。
