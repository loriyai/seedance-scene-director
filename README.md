# Seedance 场景分镜导演

当前版本：**v0.15**；更新日期：**2026-10-16**。

v0.15汇总此前本地修订，并将新创作流程升级为`scene-review-b-v2`：原写者先完成声音与必要动作骨架，处理当前声音警告后再展开详细摄影；冻结前核对同版实际渲染文本与后台时码、连续状态。记录充分的镜头身份与依赖时，增量复核可缩小至实际受影响镜头和连接；声音变化仍按整单元处理，状态变化追踪至有效收敛边界。最终完整检查与首次独立逐镜实读保留，工具不生成新的语义通过。详见[场次前检与增量复核](references/scene-review-workflow.md)。

新角色制作名省略独立“今生”段，保留原文名称、身份和世次信息；新分镜使用`none-v1`，取消黑幕ID获取、节点创建、连线及素材检查。已有台账、receipt和运行中的Canvas任务不自动迁移，历史显式任务仍保留原模式兼容。新增实测返修记录工具，不预设省时比例。

此前更新将需图片的群像改为16:9多人正面全身参考板，按剧情区分服制；增加有原文依据的佩戴形象与同场戴上/摘下检查。新声音策略按整句继承必要表现，允许有依据的片段变化；摄影复核逐镜保存具体依据，保留合理固定镜头。已有设计、分镜和画布节点不自动迁移。

v0.13新增阶段模型调度，默认启用 `stage-model-routing-v1`。实质创作阶段按配置调用Sol High子代理，已授权同步的批量准备/结果核对用Sol Medium，具体疑难语义问题可升级Astra High；短任务直接执行。主聊天模型不自动切换，全局配置不改。通过独立交接目录、输入摘要与主代理统一提交保留现有工作流；可用性取决于宿主子代理能力及账号权限。详见[阶段模型调度](references/model-routing.md)。

此前process系列修订增加逐片段文本估时诊断、最终请求与上下文摘要绑定的语义复核门槛、从session及当前有效任务派生的只读恢复摘要，以及视频逐节点完整核验进度。当前新提交须附逐镜最终稿复核记录，旧receipt重导出保持兼容；固定抬头、时长与屏幕文字策略保持原规则。详见[后台接口](references/runtime.md)。process.2另整理测试及验证说明：统一Python回归入口、合并重复场景、精确核对拒绝原因，并按实际执行场景统计CLI检查数。

后台任务使用冻结JSON与独立进度状态；同一画布单进程写入，资产支持批量申请ID和分组完整核对。资产同步期间可以继续选择范围、生成分镜，完成后再提示图片上传；已授权的视频任务按依赖排队。控制与恢复命令见[后台同步队列](references/canvas-jobs.md)。

主要道具使用`visual-continuity-v2`：保留多次独立可见使用的入选路径，另允许单段剧情中的核心物件按具体动作、视觉反差、结构交互和跨镜头参考需求入选。候选反向覆盖审阅记录入选与排除去向，分镜阶段复查当前范围的核心物件，避免旧台账漏项被直接沿用。证据和关联由程序校验，语义完整性仍须生成者通读核实；普通家具、日用品及穿戴物件按实际用途归入布景、人物或分镜描述。旧`visible-reuse-v1`台账和既有画布不会自动迁移。

背景群像也采用`visual-continuity-v2`：保留至少2次独立可见出场的复用路径，增加单段核心连续性路径；两者均需具体外观参考理由。纯文字群像须说明文字为何够用，人物登记与原文动作始终保留。该规则只适用于无姓名、无独立台词的背景群像，具名及有独立台词角色不受次数门槛限制；旧群像策略及绑定不自动迁移。分镜检查提供当前范围的复核提示和确定矛盾拦截，不自动判断重要性或将群像升级为图片资产。

v0.11 为分类视觉描述增加“角色01／场景01／道具01”编号，当时的群像图片策略为`visible-reuse-v1`。新分镜按同一聊天的批次使用“A01-场景1-分镜1”名称，TXT、云端提示词标题和视频节点一致，重试与局部修改保留名称。黑幕改为独立reference连线，不再出现在新分镜提示词中。

旧台账、旧分镜回执与未选定的画布节点保留兼容；固定抬头、时长、摄影、台词及连续性规则沿用。v0.13的本地资产同步修复覆盖阶段路由配置生效、交接输入变更、任务与产物边界、后台同步队列、道具与群像筛选及迁移兼容，以及创建后业务资产就绪、明确拒绝与未知写入区分、同ID有限重试、旧日志恢复和失败通知。离线验证不代表真实画布写入、性能或视频生成验证；这些本地修复一并纳入v0.15。

将完整中文剧本整理成标准剧本，筛选可复用资产并完成美术设计，输出适用于Gpt-image-2的资产图片提示词，再根据用户指定的剧本范围按场景生成适用于 Seedance 2.5 的分镜提示词。

本 Skill 已完整内置 `screenplay-standardizer` 的规则、参考文件与脚本，无需另外安装该 Skill。对外使用一个入口，内部按阶段加载所需规则。

## 安装

需要支持本地Skill的Codex环境，以及Python 3.10或更高版本。核心脚本使用标准库；完整剧本确认可访问并选定风格后，才会后台检查当前Python的PyYAML，缺失则直接安装并验证，已有版本不重复安装或升级。小云雀画布操作另需Node.js 16+、npm和官方CLI；首次使用时按需配置并完成浏览器授权。

安装指定版本 `v0.15`：

```bash
git clone --branch v0.15 --single-branch https://github.com/loriyai/seedance-scene-director.git ~/.codex/skills/seedance-scene-director
```

也可下载 [v0.15 源码 ZIP](https://github.com/loriyai/seedance-scene-director/archive/refs/tags/v0.15.zip)，解压后将根目录重命名为 `seedance-scene-director`。已有同名安装时，先在 Skills 目录外备份旧文件夹，再完整替换。使用自定义 `CODEX_HOME` 时，安装到对应的 `skills/seedance-scene-director` 目录。切换版本时检查 `VERSION`，每次只安装一个版本。

## 使用

输入 `$seedance-scene-director`，并发送完整剧本。

1. 确认完整剧本可访问后立即暂停，显示视频风格选项并等待用户选择；选择自定义时等待具体风格文本。用户已明确提供本项目风格或本项目已有有效风格文件时直接保存或复用，不重复提问。风格确认前不分析剧本、提取资产或运行依赖检查。
2. 保存风格后转换剧本格式，核实人物、地点和候选资产；主要道具按“多次独立可见复用”或“核心动作/视觉反差/结构交互的连续性”两条路径筛选，均须具体参考需求和原文证据。逐场反查候选去向，普通家具与日用品通常归场景或分镜动作。沿用入口已保存的风格补足独立美术设计，直接交付标准剧本 TXT、资产台账 JSON、带分类序号的完整资产图片提示词 TXT。人物图固定16:9白底，左三分之一为超大正面面部特写，右三分之二并排完整全身正视、侧视、后视图。
3. 选择是否后台传输全部视觉资产及图片描述到指定画布，任务启动后立即选择剧本范围；资产完成后再选择是否上传本地图片。后续复用已保存风格。
4. 发送起止各一至两句话的剧本范围，可使用原文或标准剧本内容。
5. 后台定位标准剧本区间，按场景生成 N 个分镜单元，并逐单元检查。
6. 交付分镜 TXT、当前批次分镜数量及总时长，再选择是否在绑定画布批量创建视频节点。
7. 指定分镜编号进行局部修改，或继续发送下一段剧本范围。

后续范围出现重叠、未覆盖间隔或顺序回退时，会显示对应剧本片段，等待用户选择继续生成或重新发送范围。

通过官方 CLI 操作用户指定的可编辑画布，支持资产节点创建与复用、本地图片上传、图片引用绑定、视频节点同步及指定节点修改或删除。视频新节点沿用小云雀默认的 Seedance 2.5 和 720P，不查询、强制设置或校验这两项。每个视频按创建节点、改名（name/title/caption）、仅设置对应分镜时长、写入正式引用编码提示词的顺序执行；时长写入保留其他生成配置。各命令分别记录官方确认，全部完成后统一回读名称、时长、提示词、节点标签和引用连线，通过后才写整节点完成回执。项目保存真实节点ID和操作进度；收到实际拒绝或未知确认即停止，核对后在同一节点续接未完成步骤，不重新创建。出现同名候选或名称、时长、提示词的人工修改冲突时，按工作流提示处理。不会自动触发图片或视频生成。

确认批量创建视频节点后，先一次盘点全部台账视觉资产，复用有效ID，自动采用完整名称及类型唯一匹配的已有节点，缺失时补建空角色、场景或道具图片节点并保存真实ID。新none-v1单元不获取或创建黑幕节点、不连黑幕边、不检查黑幕素材；历史单元按原receipt兼容，既有节点及连线不自动迁移。额外画布节点保留，空图片节点照常建立正式引用，缺图片单独记录。其他图片资产在交付TXT保留`@资产名称`，仅提示词群像使用普通文字；画布提示词由CLI编码节点引用并回读，最终检查TXT分别列缺媒体和引用失败。后补角色主图可通过CLI刷新引用，保留无关连线；单独刷新引用不改视频名称、时长或其他生成配置。写入结果不明时保留进度并停止。

每个视频的真实ID、步骤确认及最终字段与引用核对另存于`canvas/video-write-receipts/`。核心字段未通过会返回`UNCERTAIN_WRITE`并保存`uncertain`回执；引用尚未通过保存`partial`，缺图片单独记待补。恢复保留字段级初始化基线，不将中断后的人工修改当作初始值；已完成节点的name/title/caption三个名称字段均受保护。

资产台账使用 schema_version 3，区分剧情场次、物理地点与可复用布景；同一物理地点默认共用一个基础布景，日夜或拍摄方向变化不另建节点。旧项目需先复查台账及节点映射，再按用户选择升级。

## 分镜规则

- 只使用通过检查的标准剧本，人物、场景和主要道具采用资产台账名称；当前范围的关键物件反查候选审阅，发现缺少必要参考时先完成相关资产复核，不能因未入台账而跳过。
- 26～30秒为优选范围，不是硬下限；自然动作/语义完成时可用4～25秒，后台记录依据，不补动作填时长。
- 29～30 秒默认建议 11 镜，26～28 秒默认建议 9～10 镜；为自然表达可调整至 8～13 镜。不足 26 秒的单元按内容安排镜数。
- 单镜头为 1～5 秒整数，各镜头时长之和严格等于单元总时长。
- 按当前情境中的动作作用安排节奏：机械过渡优先短镜、合并或省略非关键中段；情节关键动作保留关键行为与结果；情绪氛围动作保留原文变化与必要停顿，不默认慢演。动作匹配在进行中切出、后镜接续，整组只完成一次；画面压缩不改写标准剧本。
- 表演按实际可见程度选细节；原文有转折才写触发后的弧线，听者不虚构心理，关键动作按需核对接触、路径和落点。机位与微动词库提供选择，不要求逐镜换角度或堆微动作。
- 新有声单元使用event-inheritance-v1：必要持续表现写audio.delivery，片段变化或恢复中性须有依据；现场声、内心声、画外音和旁白采用同一标准，不要求每句堆满声音描述。语速统一来自audio.speed，非默认语速独立输出。旧receipt保留旧策略；变化后重新核对时长、口型与连续性。
- 台词、说话人及发声类型以标准剧本为准。短句完整放一镜；长句按标点和语义分到各镜，每镜写实际台词部分。估时仅存后台，不按时间比例切字，不用抽象续声说明。
- 景别、主焦点、机位与运镜按本镜剧情看点选择，不设固定景别权重或默认正面/45°机位。新提交逐镜填写后台purpose说明依据；近景/特写数量、相邻与首镜面部限制改为审查提醒，检查重复画面和连续正面脸部镜头（含中近景），不机械凑比例或换角度。
- 新生成或指定修改使用reference-v3：场景行只列布景资产名、时间与天气，不输出完整heading；其后独立写人物站位。每镜以括号包住主焦点景别与转场，括号外依次填写机位与运镜、构图、景深、光照。旧reference-v1/v2及更早交付保留原版渲染。
- 新范围按同一聊天依次分配A、B…Z、AA批次，批内从01编号；TXT标题如`A01-场景1-分镜1（时长：18秒）`，视频节点同名但不加时长。重试和局部修改保留名称，后台稳定ID保留，旧receipt保持原显示方式。
- 资产阶段完成群像地点后缀、同名道具视觉复用、角色世次/形象启用及唯一名称预检。背景群像按复用或核心连续性两条路径审阅图片需求；文字已足够的群像保留剧情登记并用普通文字进入分镜。群像图片仅固定制作外观，不负责人数、队形、站位或动作连续性；需要具体成员辨识时核实为独立人物。分类视觉描述分别使用角色01、场景01、道具01编号。原文用词与制作名独立，道具图片复用不合并实体数量；预告重开或初次认亲不提前换形象。
- 分镜中纯文字群像成为至少2镜的主体或任一镜主焦点时，提示复核图片需求；覆盖完整已审出场证据却未登记该群像时，提示复核画内/画外参与。两镜不是两次独立事件，也不自动升级资产。已确定需要图片参考的群像不能以精确名称或显式别名改登记为空asset_ids的临时实体；共用一句原文不用于判定实体身份。
- 不为凑时长新增动作、重复事件、慢念、循环、空镜或无意义停顿。
- 视频风格为变量，固定渲染抬头与禁止项原样保留。
- 后台完成规划、估时和自检，分镜提示词写入交付 TXT；对话仅展示文件链接、当前批次数量及总时长和必要菜单。

默认提示词规划入口采用整数 4～30 秒；实际使用入口存在其他合法档位时，应按入口配置检查。此 Skill 生成提示词，不直接生成视频。

运行离线回归自检：
