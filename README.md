# Seedance 场景分镜导演

本 Skill 将完整中文剧本整理成标准稿，筛选并设计可复用人物、场景和主要道具，输出 Gpt-image-2 图片提示词，再按用户指定范围生成 Seedance 2.5 分镜提示词。通过明确授权的小云雀CLI操作画布，不自动生成图片或视频。当前版本为 **v0.24**，更新日期 **2026-10-24**，以 `VERSION` 为准。

本版修正角色、场景和道具生图提示词的类型适配与回读验收，统一三条资产初始化入口，保留独立描述及已有图片配置；纠正上传素材source ID与云媒体ID的混用。支持两种官方画布链接，候选空间经只读核验后保存，后续命令及跨进程恢复自动沿用；旧任务不自动迁移或解除暂停。规则分别维护于[画布接口](references/canvas.md)、[工作流](references/canvas-workflow.md)和[后台队列](references/canvas-jobs.md)。

当前修订在原有负责章节中明确共同事件的镜头组织、动作与对白同期估时、有效位移、可见表演、在场人物和关键资产引用；保留相邻两镜不得都固定的硬限制。声音估算采用统一语速与停顿范围，新稿不自动输出普通语速标签，历史回执保持原有渲染。画布任务记录未报告事件，桌面提示与聊天完成反馈分别处理，后续入口依当前用户意图衔接。标准化、资产审阅与美术设计继续按各阶段权威规则执行，职责导航见[规则归属](references/rule-domains.md#当前规则归属)。

分镜规则按叙事视角、信息组织、运镜时机与切点维护，优先选择有叙事作用的运动。表演按来源组织情绪进程、表里关系及哭戏阶段，部位词库提供有条件的中文表达，面部、身体与声音保持相容；动作过程、拟音及跨镜状态分别依对应章节处理。短节拍和一次独立整场阅读负责实际取舍，局部修改复看真实影响。按场只读上下文由storyboard_context提供，预览完成后自动绑定实际产物记录成功，storyboard_metrics从有效事件派生计量并保留明确撤销记录；沿用文字命令入口，不增加逐镜表单或审核轮次。具体规则和接口分别维护于下列三份分镜资料。

新分镜采用 **scene-text-v1 文字母稿**：范围简报一次，当前场短节拍，直接写完整提示词；作者边写边检查，每场由一位独立主审完整阅读一次，集中修订后只复看改动与受影响连接。场末只记后续需要的事实，范围末只核覆盖和场次连接。脚本负责原话、时轴、引用、编号、导出和事件计时；真实表演、摄影与连续性仍由作者和主审判断。

新稿只需[分镜工作流](references/storyboard-workflow.md)、[创作规则总集](references/storyboard-rules.md)和[文本母稿格式](references/storyboard-text-format.md)三份资料；命令另由[后台接口](references/runtime.md)索引。历史回执与旧接口边界见[历史回执兼容](references/runtime.md#历史回执兼容)。旧参考文档已退出安装包，仍被调用的兼容实现保留；安装不会迁移真实项目、资产或Canvas状态。

标准化与资产阶段按职责读取四份资料：[主流程](references/asset-workflow.md)、[标准化及复核观察协议](modules/screenplay-standardizer/INSTRUCTIONS.md)、[资产台账与审阅决定](modules/screenplay-standardizer/references/asset-ledger.md)、[图片设计与共享分组](references/asset-image-design.md)。原补充分散页的有效规则已归并，旧资产入口和设计分组兼容页已移除，活动引用直接指向对应权威文件。

## 使用

1. 发送完整剧本及风格。尚无本项目风格时先选择并保存，已有有效风格不重复问。
2. 完成标准化、来源复核、资产筛选与美术设计，交付标准剧本TXT、最终资产台账JSON、分类图片提示词TXT。内置screenplay-standardizer，无需另装。
3. 仅标准稿/资产任务到相应交付结束；完整workflow继续取得分镜范围。明确全部或起止时直接定位，范围异常才取得必要选择。
4. 按场完成文字分镜和独立审阅，正式交付TXT链接、本次数量与总时长。指定编号可局部修改，其他单元保持原版本。
5. 用户选择后再通过画布适配入口建节点、写提示词或上传图片。节点操作与图片/视频生成分别授权；停止/暂停不会因安装或恢复状态查询自动解除。

固定抬头第一行按本次确认版本恢复自然注视、眨眼、微表情、呼吸与衣物随风等英文描述；对应全文校验值与渲染测试同步更新。

格式继续使用视觉抬头、保存的风格、实际资产名与现有镜头版式。单元组织、时长与摄影选择统一见[创作规则总集](references/storyboard-rules.md)，不在入口另设规则。保留原台词、声源、事件因果及动作结果，不以镜数、时长或表现配额新增剧情。

## 安装与运行

需要支持本地Skill的Codex和Python 3.10+。完整剧本风格确认后才检查当前Python的PyYAML，缺失时安装并验证，已有可用版本不升级。画布操作另需Node.js、npm及官方CLI，按需授权。

安装到当前CODEX_HOME下的skills/seedance-scene-director；已有安装先在Skills目录外备份，确认没有活跃Canvas写者，再完整替换并核对VERSION和文件摘要。不混用不同包的模块，不写真实项目到Skill目录。公开版本从[项目仓库](https://github.com/loriyai/seedance-scene-director)选择明确tag，本地修订不会自动发布。

Python回归入口为 `scripts/self_check.py`，Skill元数据另用quick_validate检查。结构、离线测试和来源覆盖不证明实际视频效果或整体提速；耗时以本次实际事件为准。
