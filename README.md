# Seedance 场景分镜导演

当前版本：**v0.02**

将完整中文剧本整理成标准剧本并提取资产，再根据用户指定的剧本范围，按场景生成适用于 Seedance 2.5 的分镜提示词。

本 Skill 已完整内置 `screenplay-standardizer` 的规则、参考文件与脚本，无需另外安装该 Skill。对外使用一个入口，内部按阶段加载所需规则。

## 安装

需要支持本地 Skill 的 Codex 环境，以及 Python 3.10 或更高版本。Python 脚本只使用标准库，无需安装额外 Python 包。小云雀画布操作另需 Node.js 16+、npm 和官方 CLI；首次使用时按需配置 CLI，并完成浏览器授权。

将本仓库克隆到 Skills 目录：

```bash
git clone https://github.com/loriyai/seedance-scene-director.git ~/.codex/skills/seedance-scene-director
```

也可以下载仓库 ZIP，解压后将根目录文件夹命名为 `seedance-scene-director`，放入 Skills 目录。使用自定义 `CODEX_HOME` 时，放入对应的 `skills/seedance-scene-director` 目录。

## 使用

输入 `$seedance-scene-director`，并发送完整剧本。

1. 转换剧本格式，交付标准剧本 TXT、资产台账 JSON、分类视觉描述 TXT。
2. 选择是否将全部角色形象、布景和主要道具传输到指定小云雀画布；可继续选择按资产台账完整名称匹配并上传本地图片。
3. 选择预设视频风格，或输入自定义风格；风格保存到独立文件，供当前项目后续使用。
4. 发送起止各一至两句话的剧本范围，可使用原文或标准剧本内容。
5. 后台定位标准剧本区间，按场景生成 N 个分镜单元，并逐单元检查。
6. 交付分镜 TXT、当前批次分镜数量及总时长，再选择是否在绑定画布批量创建视频节点。
7. 指定分镜编号进行局部修改，或继续发送下一段剧本范围。

后续范围出现重叠、未覆盖间隔或顺序回退时，会显示对应剧本片段，等待用户选择继续生成或重新发送范围。

v0.02 通过官方 CLI 操作用户指定的可编辑画布，支持资产节点创建与复用、本地图片上传、图片引用绑定、视频节点同步及指定节点修改或删除。视频新节点默认配置为 Seedance 2.5、720P 和对应分镜时长，写入后回读校验。项目保存节点映射和操作进度；出现同名候选、人工修改冲突或参数不可用时，按工作流提示处理。不会自动触发图片或视频生成。

资产台账使用 schema_version 3，区分剧情场次、物理地点与可复用布景；同一物理地点默认共用一个基础布景，日夜或拍摄方向变化不另建节点。旧项目需先复查台账及节点映射，再按用户选择升级。

## 分镜规则

- 只使用通过检查的标准剧本，人物、场景和主要道具采用资产台账名称。
- 单元优先规划为 26～30 秒，优先自然填满 30 秒；切场、选定范围结束或全剧结束允许不足 26 秒。
- 29～30 秒默认 11 镜，26～28 秒默认 9～10 镜；为自然表达可调整至 8～13 镜。不足 26 秒的单元按内容安排镜数。
- 单镜头为 1～5 秒整数，各镜头时长之和严格等于单元总时长。
- 台词、说话人及现场说话、内心 OS、画外音、旁白类型以标准剧本为准；长台词可以连续跨镜，不重复发音。
- 不为凑时长新增动作、重复事件、慢念、循环、空镜或无意义停顿。
- 视频风格为变量，固定渲染抬头与禁止项原样保留。
- 后台完成规划、估时和自检，分镜提示词写入交付 TXT；对话仅展示文件链接、当前批次数量及总时长和必要菜单。

默认提示词规划入口采用整数 4～30 秒；实际使用入口存在其他合法档位时，应按入口配置检查。此 Skill 生成提示词，不直接生成视频。

## 文件结构

```text
seedance-scene-director/
├── SKILL.md                         工作流入口
├── agents/openai.yaml               Skill 界面信息
├── assets/fixed-header.txt          固定抬头与禁止项
├── references/                     分镜、输出及后台接口规则
├── scripts/director.py              范围、时长、对白、版本校验与渲染
├── scripts/canvas.py                官方 CLI 画布连接与节点同步
├── scripts/canvas_media.py          本地图片上传及视频参数配置
├── scripts/ensure-cli.js            按需检测与配置官方 CLI
├── scripts/self_check.py            离线回归自检
└── modules/screenplay-standardizer/
    ├── INSTRUCTIONS.md             内置剧本标准化完整规则
    ├── component.json              内置模块文件摘要
    ├── references/                 资产台账及逐场复核规则
    └── scripts/                    转换、复核、资产及改稿迁移脚本
```

项目运行数据与 Skill 文件分开保存；风格、来源范围、分镜编号及修改历史保存在项目工作目录中，不写回安装目录。

默认只调用包内标准化模块，不自动寻找本机其他同名 Skill。更新内置模块时，应同步其规则、参考文件、脚本及摘要清单。

## 验证

运行离线回归自检：

```bash
python scripts/self_check.py
```

v0.02 已通过 13 项离线回归自检及 CLI 配置脚本语法检查。自检使用临时虚构剧本，不调用 CLI 或网络。内置模块文件摘要在加载时校验。摄影目的、剧情覆盖和自然表演仍需在生成时逐单元复核；画布集成需在实际授权账号与目标画布中验证，实际视频效果需要在生成后检查。
