# Seedance 场景分镜导演

当前版本：**v0.08**；发布日期：**2026-10-13**。

v0.08 保存 2026-10-13 本次融合修改前的已安装 Skill，包含完整资产美术设计、分类及分镜展示编号、黑幕视频节点准备及 reference-v3 摄影规则。

将完整中文剧本整理成标准剧本，筛选可复用资产并完成美术设计，输出适用于Gpt-image-2的资产图片提示词，再根据用户指定的剧本范围按场景生成适用于 Seedance 2.5 的分镜提示词。

本 Skill 已完整内置 `screenplay-standardizer` 的规则、参考文件与脚本，无需另外安装该 Skill。对外使用一个入口，内部按阶段加载所需规则。

## 安装

需要支持本地Skill的Codex环境，以及Python 3.10或更高版本。核心脚本使用标准库；收到完整剧本时会后台检查当前Python的PyYAML，缺失则直接安装并验证，已有版本不重复安装或升级。小云雀画布操作另需Node.js 16+、npm和官方CLI；首次使用时按需配置并完成浏览器授权。

安装此基线版本时明确选择 `v0.08` 标签：

```bash
git clone --branch v0.08 --single-branch https://github.com/loriyai/seedance-scene-director.git ~/.codex/skills/seedance-scene-director
```

也可下载 [v0.08 源码 ZIP](https://github.com/loriyai/seedance-scene-director/archive/refs/tags/v0.08.zip)，解压后将根目录重命名为 `seedance-scene-director`；本地安装包 `seedance-scene-director-v0.08.zip` 已使用该目录名。已有同名安装时，先在 Skills 目录外备份旧文件夹，再完整替换。使用自定义 `CODEX_HOME` 时，安装到对应的 `skills/seedance-scene-director` 目录。切换版本时检查 `VERSION`，每次只安装一个版本。

## 使用

输入 `$seedance-scene-director`，并发送完整剧本。

1. 转换剧本格式，核实人物、地点和候选资产；主要道具只保留至少2次独立可见使用且需要固定外观的物件，普通家具与日用品归场景或分镜动作。
2. 选择统一风格并补足独立美术设计，交付标准剧本 TXT、资产台账 JSON、带分类序号的完整资产图片提示词 TXT。人物图固定16:9白底，左三分之一为超大正面面部特写，右三分之二并排完整全身正视、侧视、后视图。
3. 选择是否将全部角色形象、布景和主要道具传输到指定小云雀画布；可继续选择按资产台账完整名称匹配并上传本地图片。后续复用已保存风格。
4. 发送起止各一至两句话的剧本范围，可使用原文或标准剧本内容。
5. 后台定位标准剧本区间，按场景生成 N 个分镜单元，并逐单元检查。
6. 交付分镜 TXT、当前批次分镜数量及总时长，再选择是否在绑定画布批量创建视频节点。
7. 指定分镜编号进行局部修改，或继续发送下一段剧本范围。

后续范围出现重叠、未覆盖间隔或顺序回退时，会显示对应剧本片段，等待用户选择继续生成或重新发送范围。

通过官方 CLI 操作用户指定的可编辑画布，支持资产节点创建与复用、本地图片上传、图片引用绑定、视频节点同步及指定节点修改或删除。视频新节点沿用小云雀默认的 Seedance 2.5 和 720P，不查询、强制设置或校验这两项。每个视频按创建节点、改名（name/title/caption）、仅设置对应分镜时长、写入正式引用编码提示词的顺序执行；时长写入保留其他生成配置。各命令分别记录官方确认，全部完成后统一回读名称、时长、提示词、节点标签和引用连线，通过后才写整节点完成回执。项目保存真实节点ID和操作进度；收到实际拒绝或未知确认即停止，核对后在同一节点续接未完成步骤，不重新创建。出现同名候选或名称、时长、提示词的人工修改冲突时，按工作流提示处理。不会自动触发图片或视频生成。

确认批量创建视频节点后，先一次盘点全部台账资产，复用有效ID，自动采用完整名称及类型唯一匹配的已有节点，缺失时补建空角色、场景或道具图片节点并保存真实ID。同次盘点检查完整名称为“黑幕”的视频节点，唯一复用或缺失补建并保存ID；该节点不写剧情prompt/时长、不计分镜统计，中断按同一ID续接。旧图片黑幕按旧分镜映射保留。额外画布节点保留，空节点照常建立正式引用，缺图片和缺黑幕视频素材单独记录。交付提示词TXT保留原有`@资产名称`，画布提示词由CLI编码节点引用并回读；最终检查TXT分别列缺媒体和引用失败，不清空提示词、不用网页粘贴补救。后补角色主图可通过CLI刷新引用，保留无关连线；单独刷新引用不改视频名称、时长或其他生成配置。写入结果不明时保留进度并停止。

每个视频的真实ID、步骤确认及最终字段与引用核对另存于`canvas/video-write-receipts/`。核心字段未通过会返回`UNCERTAIN_WRITE`并保存`uncertain`回执；引用尚未通过保存`partial`，缺图片单独记待补。恢复保留字段级初始化基线，不将中断后的人工修改当作初始值；已完成节点的name/title/caption三个名称字段均受保护。

资产台账使用 schema_version 3，区分剧情场次、物理地点与可复用布景；同一物理地点默认共用一个基础布景，日夜或拍摄方向变化不另建节点。旧项目需先复查台账及节点映射，再按用户选择升级。

## 分镜规则

- 只使用通过检查的标准剧本，人物、场景和主要道具采用资产台账名称。
- 26～30秒为优选范围，不是硬下限；自然动作/语义完成时可用4～25秒，后台记录依据，不补动作填时长。
- 29～30 秒默认建议 11 镜，26～28 秒默认建议 9～10 镜；为自然表达可调整至 8～13 镜。不足 26 秒的单元按内容安排镜数。
- 单镜头为 1～5 秒整数，各镜头时长之和严格等于单元总时长。
- 按当前情境中的动作作用安排节奏：机械过渡优先短镜、合并或省略非关键中段；情节关键动作保留关键行为与结果；情绪氛围动作保留原文变化与必要停顿，不默认慢演。动作匹配在进行中切出、后镜接续，整组只完成一次；画面压缩不改写标准剧本。
- 台词、说话人及发声类型以标准剧本为准。短句完整放一镜；长句按标点和语义分到各镜，每镜写实际台词部分。估时仅存后台，不按时间比例切字，不用抽象续声说明。
- 景别、主焦点、机位与运镜按本镜剧情看点选择，不设固定景别权重或默认正面/45°机位。新提交逐镜填写后台purpose说明依据；近景/特写数量、相邻与首镜面部限制改为审查提醒，检查重复画面和连续正面脸部镜头（含中近景），不机械凑比例或换角度。
- 新生成或指定修改使用reference-v3：场景行只列布景资产名、时间与天气，不输出完整heading；其后独立写人物站位。每镜以括号包住主焦点景别与转场，括号外依次填写机位与运镜、构图、景深、光照。旧reference-v1/v2及更早交付保留原版渲染。
- 新分镜TXT按文件内顺序从01加展示号，如`01 - 场景1-分镜1（时长：18秒）`；稳定ID、视频节点名及云端提示词仍使用原编号。旧receipt保留原显示方式。
- 资产阶段完成群像地点后缀、同名道具视觉复用、角色世次/形象启用及唯一名称预检。原文用词与制作名独立，道具图片复用不合并实体数量；预告重开或初次认亲不提前换形象。
- 不为凑时长新增动作、重复事件、慢念、循环、空镜或无意义停顿。
- 视频风格为变量，固定渲染抬头与禁止项原样保留。
- 后台完成规划、估时和自检，分镜提示词写入交付 TXT；对话仅展示文件链接、当前批次数量及总时长和必要菜单。

默认提示词规划入口采用整数 4～30 秒；实际使用入口存在其他合法档位时，应按入口配置检查。此 Skill 生成提示词，不直接生成视频。

## 文件结构

```text
seedance-scene-director/
├── SKILL.md                         工作流入口
├── agents/openai.yaml               Skill 界面信息
├── assets/fixed-header.txt          固定抬头与禁止项
├── references/                     分镜、输出及后台接口规则
├── scripts/director.py              范围、时长、对白、版本校验与渲染
├── scripts/dialogue_layout.py       完整台词、逐镜自然分句与旧版兼容
├── scripts/canvas.py                官方 CLI 画布连接与节点同步
├── scripts/canvas_media.py          本地图片上传及视频时长设置
├── scripts/canvas_reference_report.py 缺图片及引用失败检查TXT
├── scripts/ensure-cli.js            按需检测与配置官方 CLI
├── scripts/ensure_dependencies.py   检查PyYAML，缺失时后台安装并验证
├── scripts/self_check.py            离线回归自检
├── scripts/test_dialogue_layout.py  台词布局回归检查
└── modules/screenplay-standardizer/
    ├── INSTRUCTIONS.md             内置剧本标准化完整规则
    ├── component.json              内置模块文件摘要
    ├── references/                 资产台账及逐场复核规则
    └── scripts/                    转换、复核、资产及改稿迁移脚本
```

项目运行数据与 Skill 文件分开保存；风格、来源范围、分镜编号及修改历史保存在项目工作目录中，不写回安装目录。

默认只调用包内标准化模块，不自动寻找本机其他同名 Skill。更新内置模块时，应同步其规则、参考文件、脚本及摘要清单。

## 验证

运行离线回归自检：

```bash
python scripts/self_check.py
python -m unittest discover -s scripts -p "test_*.py"
node scripts/test_cli_capabilities.js
```

自检使用临时虚构剧本与画布mock，不调用真实CLI或网络，覆盖逐镜台词、动态镜数/时长、新旧模板、提交幂等、资产命名复用、实体记录、形象启用及迁移，以及范围数值、声源、逐场证据、输出目录保护、引用验收、删除摘要和人工气口。Node检查用mock验证必要命令探测，不执行CLI安装。内置模块摘要在加载时校验。摄影目的、剧情覆盖和自然表演仍需在生成时复核；画布集成及实际视频效果需在授权使用时另行验证。
